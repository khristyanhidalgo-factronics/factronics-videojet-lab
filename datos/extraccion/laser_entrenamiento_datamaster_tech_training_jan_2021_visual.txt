Requirements for PC/Network
PC/Network side requirements:
ummary: etwork should be fast and separate
Windows or 1 PC. Data Master Version 1.5.5 is compatible with Windows 1 Pro, Windows 1 Pro
for Workstation and Windows 1 Enterprise based operating systems.
If the PC is to be connected directly to one laser system, the connection must be made using a
crossover ethernet cable.
If the PC is to be connected to several laser systems, the connection must be made using a reliable
Gigabit switch of industrial quality.
If the DataMaster software is used with several laser systems, it is expressively recommended to run
the laser systems in a separate subnet via a different network card or network switch and not via the
home network.
Important: Within this subnet, only the laser systems which are used with DataMaster software
should be available!
The cables which are used should be industrial quality, preferably CAT-.
No other software (including antivirus software -neither real-time protection nor scheduled drivers
scan, automatic updates) should run on the same PC as DataMaster software, neither should an
external operating panel (Handheld) be connected.
The Firewall of the connected PC must be deactivated.
