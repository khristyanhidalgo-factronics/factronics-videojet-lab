1 Simple Operator Interface (SOI)
1.1 Introduction
The Simple Operator Interface (SOI) is an easy-to-use and convenient program to select andmodify messages which are to be marked with the laser system and to start the actual marking
process. The software can be run on a normal PC or a touchscreen. Upon start-up, it connectswith the laser system and can access the messages which are stored in the laser database.
1.2 Requirements
To operate the software properly the following hardware and software requirements have to bemet:
Microsoft Windows 2000, XP or Vista
Pentium IV Processor > 2 GHz
1024 MB RAM
CD-ROM drive (optional - if SOI software is to be installed from CD-ROM)
200 MB hard disk memory
1.3 Installation
NoteTo create new messages the Smart Graph software is required.
For more information about creating messages (so-called templates in theSmart Graph) please refer to the manual of the Smart Graph software.
NoteIf the PC is to be connected directly to the laser system (and not via network)the connection must be made using a crossover ethernet cable. Otherwise
communication is not possible.
If the SOI software is not delivered pre-installed, please proceed as follows to install the SOI:
1.Insert the SOI software CD-ROM inload the corresponding files down onto your PC.to the CD-ROM drive of your PC or
2.Select »Execute« from the start-menu of your Windows operating system.
3.Enter CD:\setup.exe in the text field and follow the instructions of the InstallShield wizard(CD is a place holder for the letter of the CD-ROM drive in your PC, if you install after download
please enter the corresponding drive letter).

2.2 System States of the Laser System
The current state of the laser system is displayed on top of the active laser page.
There are the following system states:
System StateDescription
InitializeThe control components of the laser system are started.
Key-switch openThe initialisation is complete. The system can now be started byclosing the key-switch.
Laser start-upAfter closing the key-switch the laser and the cooling system areactivated.
Laser readyThe laser system is ready for marking.
Prepare for markingAfter pressing »START« the laser requires a preparation time,the length depends on the template contents and the configura-
tion.
MarkingThe current marking content is marked onto the product.
Laser radiation is emitted! Make sure that the safety instructions are observed.
StandbyIf no marking is carried out for some time the laser switches tostandby in order to relieve the system components.
Interlock openThe safety circuit is interrupted (e.g. protective door open). Amarking process is stopped immediately. Marking is only possi-
ble with closed safety circuit.
ErrorAn error occurred. To continue operation the error must be con-firmed. Information on the error can be found on page »Mes-
sages«.
Fatal errorA fatal error occurred and has deactivated the system. This errorcannot be confirmed and the operation cannot be continued.
The laser system has to be turned off. Information on the errorcan be found on page »Messages«.
Service modeThis system state enables service and maintenance work andmust only be used by especially trained personnel.

2.5 Modify Positioning
To change the positioning of the marking contents click onto the corresponding button (hori-zontal, vertical, or rotation) in the toolbar.
To the left, a keypad is displayed. You can enter the desired offset or rotation value directly viathe keypad. The entered value is displayed in the top field of the keypad. The positioning must
be confirmed by pressing OK on the keypad section.
You can also shift the message content in steps via the buttons displayed in the preview win-dow:
Horizontal positioning.By clicking on the buttons, the marking content is moved to the left/right in
steps. The offset value is displayed in the top field of the keypad.
Vertical positioning.By clicking on the buttons, the marking content is moved up/down in
steps. The offset value is displayed in the top field of the keypad.
Rotation.By clicking on the buttons, the marking content is rotated left/right in steps.
The offset value is displayed in the top field of the keypad.
The original position is indicated by a dotted cross, the new coordinates by a normal cross.

2.10 Alerts
There are three different types of alerts:warnings
errorsfatal errors
A list of all available warnings and error messages can be found in the operating instructionsof the laser system.
Warnings are displayed in yellow, errors and fatal errors in red. If there are both types of alertsthe background will be red.
If there is only one alert, it can be confirmed dicurrent laser status will be displayed.rectly by clicking onto button »Confirm«. The
If there is more than one alert, two triangles with exclamation marks are displayed together withthe number of alerts and the arrow icon pointing downwards (see figure below).
Clicking on the arrow icon, the alerts are displayed. They can be confirmed individually (button»Confirm« to the right of the alert) or all at once (button »Confirm all« at the bottom). Clicking
again on the arrow icon, the list is closed.
Clicking onto one alert, more details are displayed.
After confirmation, the number of alerts is updated automatically. If all alerts are confirmed, thecurrent laser status is displayed.
