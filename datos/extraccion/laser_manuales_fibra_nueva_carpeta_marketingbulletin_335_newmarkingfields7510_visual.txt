21 July 2015 Issue No. 335
CHANGES IN MARKING FIELD SIZES FOR 7510 LASER
Through recent application feedback, it has been
noted that the 7510 laser marking system has
experienced issues with back reflections from the
lenses. This condition could result in damage to th e
marking heads. To correct this issue, we are
implementing adapter rings that slightly change the
size of the marking fields.

Update Process
If a laser system up to serial number Y1504/023 wit h the CMark software up to version 1.2.0.7 is to be updated, the
following needs to be carried out:
Scan lens Description
F100 The lens AL-94310 is to be replaced by FO-1124 09
F160 The lens is obsolete
F163 The lens with the adapter ring (Assembly FO-12 2240) is to be changed
F254 The adapter ring FO-112402 is to be added
F420 No change
Important: After updating the following error message is disp layed:
Proceed as follows:
1. The marking head CP10 is to be selected in the s oftware under:
Configuration -> Marking head in the field Marki ng head.
2. The appropriate lens is to be selected in the so ftware under:
 Configuration -> Marking head in the field Sel ect objective.
3. The laser system is to be restarted.
4. The working distances are to be adjusted.
