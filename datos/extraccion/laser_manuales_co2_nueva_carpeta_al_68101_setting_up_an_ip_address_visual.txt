1 IP address setup for a direct connection between PC and laser system
This document describes how to use set up an IPsystem via a cross patch cable directly to your address if you wish to connect your laser PC and do not establish the connection via In-
tranet.
1.1 Setting up the IP address on the laser system
As setting up the IP adress on the laser system depends on whether the system is equippedwith an ACC2 or an ACC3 board, please find the respective descriptions as follows:
1.1.1 Setting up the IP address on the laser system with an ACC2In order to find out the IP address of your laser system, please proceed as follwos:
1.Press the "Info" button on your touch panel. The current IP address can be found in the appearing dialog.
2.Make a note of the IP address, as you will need it to set up the IP address under the Windowsoperating system, see page Seite2.
1.1.2 Setting up the IP address on the laser system with an ACC3In order to set up the correct IP address on the laser system, please proceed as follows:
1.Make sure that the DIP switch 1 on the ACC board (see figure below) is set to ON.
DIP switch 1 ON:The IP address 192.168.1.1 with subnet mask 255.255.255.0 issaved in the system database. Via this address the PC can commu-
nicate with the laser system.
The DIP switch 1 is set to ON when the laser system is delivered.
NoteDIP switch 2 on the ACC board has no function.
