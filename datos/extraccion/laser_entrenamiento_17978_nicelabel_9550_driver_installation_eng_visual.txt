P r i n t er S et t i n g s
This section explains the Printer Settings required once the driver is installed for NICELABEL. It is
recommended that all settings to be controlled by the printer are set in Clarity Configuration Manager .
The only settings that should be set in the driver are Media Width, Height, and Rotation. All others will
be set to Use setting set on printer .
1 . Click the Windows Start Button on the taskbar , then select Settings . The Windows Settings
menu will display .
2 . Select Devices , then select Printers & Scanners .
3 . Select the Nicelabel driver , then select Manage .
