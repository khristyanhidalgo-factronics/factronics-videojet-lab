1.1 Requirements
Wireless network
Available signalCheck the signal strength to define the best position for the access box!
Ambient temperature between 5 and 40 C
The system must be equipped with Chameleon AL-80518 (red) or newer. Older boards do not support the access box!
The operating software must be CMark 5.0 or higher.Older versions do not support the access box.
1.2 Installation PossibilitiesNoteThe access box AB210 is only to be used with the laser systems 3350/CSL30.
The access box AB220 is only to be used with the laser system 3350.
The laser system supports the access box starting from CMark version 5.0.
