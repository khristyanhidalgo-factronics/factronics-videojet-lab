Industrial Protocols - Profinet
V ideojet supports two common Industrial Protocols, the Profinet protocol is covered in this
document.
Profinet
Used primarily with Siemens PLC’ s
Profinet (usually styled as PROFINET , as a portmanteau for Process Field Net) is an industry
technical standard for data communication over Industrial Ethernet, designed for collecting data
from, and controlling equipment in industrial systems, with a strength in delivering data under tight
time constraints (on the order of 1ms or less). The standard is maintained and supported by
PROFIBUS & PROFINET International (PI), an umbrella organization headquartered in Karlsruhe,
Germany .(2019 - Sep Wikipedia - Profinet).
Certifications and Performance
PROFINET is certified as Conformance Class C and has a cycle rate of 250 μs (microseconds).
Performance Metrics such Product Count, Mark Count, Batch Count are not updated in real time,
but are updated at least every 100 milliseconds.
Certifications are available on Sharepoint. Contact V ideojet T echnologies, Inc Laser T echnical
Support for certifications.

Limitations
CLARiTY Laser Controller cannot be used with PROFINET . SmartGraph, TCS+, and most
SARs (including Ultimate) can be used with PROFINET .
CPU load is increased by approximately 10%, when using PROFINET .
Only ASCII characters are supported. No Unicode may be used.
Maximum of five variable fields per (Packet) transmission.

Enable the Profinet board

The Profinet board needs to be configured in W eb Interface page before the use.
The Profinet has its own part number and is specific to this protocol. It is not possible to change the
firmware and software if the wrong part is ordered, the solution is simply to order the correct board.
Following the installation of the board, complete the following steps to enable and configure the
board.
1) Connect to W eb Interface.
2) Click on Other menu from the home screen.
3) Select External Interface from the drop-down menu.
4) From the drop-down menu under the Other icon, select the External Interface icon, next select
the Profinet selection. Select the Save icon, to save the configuration setting.
5) The default configuration is DHCP , to enter a Host Name for the PLC, remove the check mark
and enter the static IP for the Ethernet/IP board.
pic
6) Click Save button.

7) Power cycling the unit is not required. The system reloads the changes, the minimum wait is two
(2) minutes as the system connects to the Ethernet/IP board. When the Ethernet/IP board has been
acknowledged, the system screen and Status will show Active . Additional information such as the
MAC Address and Firmware version will be populated.
8) Install the cable from the PLC to either port on the board and that port will change from NoLink to
Connected when activity is present. T o test without a PLC connected, you may connect Ethernet
from either port on Chameleon board to board and the status of Port1 or 2 should change.
Remember to return the Ethernet cable back to its original position once testing is complete.

9) Laser system is now configured for use with the appropriate PLC. Customer documents
regarding programming, such as GSD, EDS, and Sample Projects, should be provided to customer
for programming their PLC for use with the laser system.
