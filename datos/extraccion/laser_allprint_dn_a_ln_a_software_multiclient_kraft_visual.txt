Software MultiClient – Aplicação Gaming
1) Software MultiClient
2) Clicar em “Config” para configuração dos IPs e clicar em “Apply”

3) Para carregar a base de dados clicar em “Data”
4) Após carregar a base de dados clicar em “Connect”

5) Clicar UMA vez em “Refresh”
6) Clicar UMA em “Start Server”
7) Iniciar o laser apertando o botão VERDE (Start)
8) Caso ao abrir o MultiClient aparecer a tela abaixo:
SIM / YES → Caso a base de dados ainda não acabou e deseja continuar utilizando
NÃO / NO → Caso a base de dados já acabou e deseja carregar uma nova
