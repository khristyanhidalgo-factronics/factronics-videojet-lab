Laser – Terminos Tecnicos
• Pump Chamber : Consists of laser lamp, resp. laser diode array y Nd:YAG - rod.
Generates together with the outcoupling y end espejo the radiaton.
• Resonador : All optical componentes between outcoupler y final espejo.
• Q - Switch : RF - controlled optical switch. Turns off the Haz Laser for the jumps y
turns on before the marking vectors. Generates the pulses in pulsed mode operation.
• Mode Aperture : Varies the Haz Laser diameter y with that, el haz laser calidad.
• Beam - Shutter : Electro - mechanical safety feature. Interrupts the Haz Laser inside
the Resonador, if the interlock circuit is opened or the laser is stopped.
• Modulo de Expansion : Expands the Haz Laser. This leads to a smaller punto focal.
• Scanner head : Consists of two scanner espejos. These deflect the Haz Laser
according the template, to x - y y - positions.
• Objectiva : Focuses the expanded Haz Laser onto the product surface (punto focal).

The Filling Parameter – Line Width -
The filling parameter line width, defines the actual line width for e.g. barcodes
on the product. The parameter highly depends on the material y is defined by
measuring the line width on the product. After that the software calculates the
neccessary amount of strokes, to fill one module of a barcode.
The line width is adjustable from 0.01 to 1.6 mm.
When this range is exceeded, the max. acceptable value is displayed.

Booting the System
After Power on, the System starts the initialization y goes through
the following steps:
• The Power PC on the ACC - 2 starts the bootloader program from the boot flash y initializes the
ACC - 2 Hardware. It loads a default image into the FPGA that makes it possible to access the MMC
in the next step.
• The Power PC loads the LINUX image from the MMC y starts it.
• LINUX is booted y initializes some parts of the ACC - 2 y loads drivers for the hardware.
• The start script of LINUX starts the Smart OS.
• The Smart OS reads the system database from the EEPROM y the application database from the
MMC y stores them in the volitile memory of the SDRAM.
• The Smart OS transfers an updated image to the FPGA y the program for the DSP to the ACC - 2‘s
Digital Signal Processor (DSP).
• Meanwhile the MDBs on the LHC y LPC have started their own bootloader programs y are
waiting to receive their application over the CAN - Bus.
• The Smart OS checks the Versions of LHC y LPC y sends the appropriate programs to them.
• The ACC - 2 changes the system state to “KEYSWITCH OPEN“.
