Allprint BasicFundamentals
Creation and testing of an Allprint Basic file
1.Define the desired marking: Determine the variables and the data transfer.
2.Boot the laser with the standard database in order to delete existing Allprint Basic files.
3.Create a template with the desired variables in the Smart Job software and assign it to a job.
4.Create an Allprint Basic file.
5.Transfer the Allprint Basic file to the laser system via Transfer -> DBF file in the Smart Job.
6.Save the database.
7.Switch the laser system off and on again to activate the Allprint Basic program.
8.Transfer the data string, e.g. using a terminal program.
9.Start the marking process and check the marking result.
