Case# E00899 NAME 2nd Full CLARiTY Binary Port Type: Enhancement
Summary Description Required Software Version (or later)
Configurable but is by default set to 0
CCM CLARiSOFT
Not Applicable Not Applicable
Details:
After updating and re-powering the printer there will now be two full Binary Com ports
available, primarily for OEM HMI integration while being able to also hold connection
with CLARiNET.
* View in the User Interface at
Tools/Diagnostics/Control/Communications/TCPIP/CLARiTY Communications/Port1/2.
* STRONG advice to keep the original Binary CommsNetworkPort as 3001.
* Set Port2 in CCFG under System/TCPIP/BinaryCommsNetworkPort2.
* Set Port2 to any other value (that does not interfere with any other TCPIP
Communication).
Please note that:
* It is intended to use one port for monitoring and the other for configuring. If both
ports are used for configuring the same parameters there could be issues including 'race-
conditions'.
* it is expected behaviour to lose Text coms for a very brief period when
uploading/downloading from CCFG.
* Please note that with more communication channels open at the same time there is
increasing likelihood of the printer running out of RAM memory, thus leading to faults.
Channels such as Binary Ports 1 & 2, Master/Slave, Text Coms, Emulation modes such as
ZPL/Sato/CimComs & Webserver.

Case# E00908 NAME Arabic Date Improvements Type: Enhancement
Summary Description Required Software Version (or later)
New Arabic Date Formats Supported
CCM CLARiSOFT
Not Applicable Not Applicable
Details:
The following date formats are now supported by the CLARiTY Laser Controller when
using the Arabic Encryption:
d (Day of month with no leading Zero)
dd (Day of month with leading Zero)
M (Calendar month with no leading zero)
MM (Calendar month with leading zero)
y(2010=0) (year of century with no leading zero)
yy (2-digit year e.g. 14)
yyyy (4-digit year e.g. 2014)
The fields will have to be created in CLARiSOFT with the font 'Standard_Font_1_arabic'.
These fields will also need the Encrypted Field set to 'CLARiTY.Encryption.Arabic' in
CLARiSOFT.

Case# E00910 NAME Barilla Dates Now Supported Type: Enhancement
Summary Description Required Software Version (or later)
Barilla Date is a special day offset of Julian Day + 400 days.
CCM CLARiSOFT
Not Applicable Not Applicable
Details:
First, a special Script File will need to be installed on the Laser's MMC card, please see
your Laser Technical Support Representative for this.
Secondly, the Barilla date field will have to be created in CLARiSOFT with the following
applied:
1. Create a new Date field.
2. In its Property Box, click on the 'Advanced' button.
3. Remove all default Selected Formats.
4. In the drop-down box at the bottom, select 'Claricom.BarillaJulianDate' and click Add.
5. In this date field's Property Box's General TAB, ensure that the Field name is the same
as that in the MMC Card Script file.

Case# E00953 NAME CLARiTY Laser Controller now Type: Enhancement
supports Transmitted Fields
Summary Description Required Software Version (or later)
CLARiSOFT 4.408 SP14 (or newer) required to generate CIFF files
CCM CLARiSOFT
Not Applicable 4.408 SP14
Details:

Note that ASCII, UTF8 and UNICODE are supported as are Parse Escape Sequences.

Case# E01010 NAME New JDAS, JDIS & JDUS Text Type: Enhancement
Commands
Summary Description Required Software Version (or later)
The commands JDUS, JDAS & JDIS are the same as JDU, JDA & JDI, except
that they save the job changes permanently.
CCM CLARiSOFT
Not Applicable Not Applicable
Details:
If a CLARiTY printer is re-powered after one (or more) JDA/JDU commands the printer
will restart displaying the original value upon initially loading the job, not the updated
values.
This could cause confusion.
JDAS, JDIS & JDUS are now available that essentially do the same tasks as JDA/JDI/JDU
while also permanently saving the changes to the internal memory card.
Using JDAS, JDIS & JDUS commands will keep CLC & Marking System in synch after a
system re-power.
Note: JDAS, JDIS & JDUS should be used sparingly as excessive use can drastically reduce
the life of the internal memory card.

queued up
Summary Description Required Software Version (or later)
Allowing the system to stay in-sync if repeated commands are sent too quickly
CCM CLARiSOFT
Not Applicable Not Applicable
Details:
An issue was reported where a number of remote Text Com commands were sent in very
quick succession. This resulted in the marking system and the CLC becoming out of sync.

for the laser to accept, CLARiTY will queue them up and send them down as and when
the marking system is ready.

Case# B00879 NAME Job Download Failure Fixes Type: Bug Fix
Summary Description Required Software Version (or later)
Two known issues that could cause Job Download Failure are now resolved
CCM CLARiSOFT
Not Applicable Not Applicable
Details:
Failure 1: There should only ever be 1 CLARiTY designed job on the laser at any one
time (which should be over-written with each job select from CLARiTY Pod). If,
somehow, more than 1 CLARiTY job managed to find its way on to the Laser, subsequent
job selects would fail. This is now resolved by way of 'cleaning up' residual CLARiTY jobs
on each new job select.
Failure 2: If for some reason the CLARiTY Pod thought it lost power (e.g. removing the
PCB battery), subsequent Job Selects would result in “Job Download Failed”, even if the
“E1014 Time and Date may be incorrect” warning had been cleared. Now, once this
warning has cleared, Job Selects will succeed.

Case# B00929 NAME Very Large jobs would previously not Type: Bug Fix
load from the CLC
Summary Description Required Software Version (or later)
CLC could also enter E6220 Laser Marking Head Absent.
CCM CLARiSOFT
Not Applicable Not Applicable
Details:
Very large jobs would never load even though they would appear to have done so at the
CLC, with no indication otherwise. This would cause confusion as to why the previous
job was still being printed.
Now, jobs over the maximum packet size are partitioned into multiple smaller messages
(buffered) as they are sent down, so even very large jobs load and print without issue,
provided all fields are within the marking area and the key-switch is not toggled during
job loading.
Jobs with up to 200 fields have been tested, note: this is the maximum number of fields
allowed by CLARiSOFT.
Jobs that take up to 10 minutes to load have been tested.

Update Procedure
In order to update a machine with a previous software revision to the latest you should use
a USB memory device or the latest CLARiTY Configuration Utility.
a) To use a USB memory device, the CAB update file requires copy and pasting into a
‘CLARITYupdate’ folder in the root of the USB device. Insert the USB device into the port
on the printer and after a short while the screen may show an option to load new
software, depending on the printer settings in CCFG. If it does select ‘Yes’ then select the
required update, press ‘OK’ and follow on-screen instructions. If it does not, keep the USB
device in the printer and on the printers User Interface scroll to
Tools\Setup\Control\CLARiTY Update, select the required update and press ‘OK’ and follow
on-screen instructions.
b) To use the CLARiTY Configuration Utility, start the utility, and connect it to the printer
you wish to update. Ensure that the CLARiTY Configuration Utility has a valid TCP/IP
connection to the printer; this can be observed by the printer icon turning green, and the
"Active Connection" message being displayed in the status pane.
Right click on the name of the coder you wish to update and select the CLARiTY Update
option. Then locate the file with the same name as the part number above, and the
CLARiTY Update will then proceed automatically.
