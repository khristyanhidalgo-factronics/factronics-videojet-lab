Release of the Chameleon Board AL- 84620
This bulletin is to inform you of the upcoming release of the MC Chameleon Board AL- 84620 -
Board, PCBA, Chameleon, MCIP ATRIX.
Due to to global supply chain shortages, it is necessary to introduce a new MC Chameleon
board for the interim to maintain laser unit production and availability of spare parts. The MC
Chameleon board contains changes in components, while modifying and maintaining the ori -
ginal design intent and functionality.
Figure 1: MC Chameleon Board
l
The new AL- 84620 Chameleon board will be introduced with index AB. For easy iden -
tification, the new board is red in color.

l
The board replaces the previous versions: AL- 76158, AL- 78900 and AL- 83300.
l
The AL- 84620 MC Chameleon PCBA requires the minimum use of CMark 4.15.1 or greater.
Points of Difference
l
The connections located on the board​ and the installation/exchange of the board remain the
same.​​
l
Note : It is not possible to load the customer data from CMark versions: 3.4.x and CMark
4.x.0. The current mitigation in this case is to export the following prior to updating: tem -
plates, line setups, mark sets, logos, and fonts.
l
The AL- 84620 has no SD card socket. When upgrading from a SC Chameleon board with an
SD card, refer to the service instructions AL- 77300 for the data transfer.
l
The USB connector located on the Chameleon board remains functional. ​​​The function is for
using the rescue stick.
l
The USB connector located on the front panel for the 7510, 7610, and 7810 is no longer
supported.
l
When powering off the laser system, the status LED located on the power button will flash for
a brief period of time. This behavior is unique to the AL- 84620 MC Chameleon board, which
has no impact on the performance of the PCBA. This behavior will be corrected with the next
release for the MC Chameleon board. This behavior is to be corrected in revision AC
l
Processors: Different manufacturers for the processors will be used. If necessary, these are
easily identified by the color and facing direction of the heat sink.
l
Rescue Stick
l
The Rescue Software version required for the AL- 84620 Chameleon board is PlexMark
1.14.
l
There is a risk when using a previous version that the laser will not boot. The Rescue pro -
cess would install the Cmark.zip file, however the system would not be able to shut down
(screen would still be on and displaying an error message, the White LED will be flashing,
no Blue LED). The next Boot sequence based on the Cmark version used with the Res -
cue stick, the system may not boot and the system could not be powered down.
l
The corrective action is use the current Rescue Software version.
