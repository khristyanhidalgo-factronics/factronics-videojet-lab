AL-64152Service Part Installation Instruction
Exchanging of the Focusing Optics for LC100/3120 (SHC100/120)
1 Exchanging of the Focusing Optics for LC100/3120 (SHC100/120)
The following is required for exchanging the focusing optics:
Double offset screw driver 6-edged 3 mm
1.1 Dismounting
DangerThe laser system must be disconnected from the power supply withoutfail before starting with the activity.
1.Turn the key-operated switch in the position »0«.Remove the key, in order to ensure that the laser system cannot be
switched-on.
2.Save the database in the For a detailed description see the manual of thesoftware. software.
3.Turn-off the main switch.
4.Pull the mains plug.
ImportantAlways wear gloves while carrying out these activities!
1.Loosen both fixing screws of the focusing module and remove it from the marking head.
2.Place the focusing module on a clean surface.
