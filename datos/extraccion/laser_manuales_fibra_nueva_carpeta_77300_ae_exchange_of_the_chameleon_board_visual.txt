AL-77300Service Part Installation Instruction
Exchange of the Chameleon Board
1 Exchange of the Chameleon Board
NoteFirst go to the Laser Web Interface and take note of the current laserconfiguration. The values need to be entered after installing a new
board.
If you exchange a Multi-Core for a Multi-Core Chameleon board youhave to make a CMark backup:
Start the laser system, connect to the Laser Web Interface.
Note: You must connect via primary IP with Dip Switch 1 Off! Web Interface functions that upload from the laser require that you connect
to the primary IP address set in Laser/Configuration menu.
You cannot upload to or download from the laser when connected via the default IP with Dip Switch in the On position if the primary IP configured is
different from the default. It is not possible to upload or download using the secondary IP (if it exists).
Only the primary IP with Dip Switch 1 Off position will allow for functions with file transfer in the Web Interface.
In the Laser Web Interface login with service username and password and select menu Other -> CMark backup.
Click the button Backup.
Note: Only one backup at a time allowed!If any existing backup already exists on the system, it must be deleted
before a new backup can be created. This is due to storage space limitations. Backups are deleted from the system automatically on laser
shutdown.
The Web Interface is locked during backup creation until the process is complete or until failure. Backup takes approximately 8-10 minutes. If the
backup fails, a dialogue box will display the reason for failure.
If successful, the backup file name will display in the dialogue box.

Update Software
2 Update Software
2.1 Single Core exchanged for Single Core Chameleon board (76158 -> 76158)
1.Insert the SD card retained from the previous board into the newly installed Single CoreChameleon board.
2.Press the button Power/Standby to restart the system.
3.Reconnect to the Web Interface after the boot process is complete.
4.Login to the Web Interface with service username and password and select Laser ->Config from the homepage.
5.Set the Laser Type, Marking Head Type, Lens, Serial Number, and CPD/SPM/FASSconfiguration at a minimum.
6.Click the button Save. A reboot is necessary after clicking Save before you can completeany additional actions.

Service Part Installation InstructionUpdate Software
2.4 Uploading Calibration Files
NoteThis only applies to the systems 7x40 and Y.0x00-xs.
1.Log into TCS+/FOBA Go as "Service".
2.Go to Global Settings and select Laser Unit Settings.
3.Select Lens Compensation and select File Management.
4.In the File Management dialog select Upload and navigate to the USB stick containing thecalibration file (on the connected Laptop, PC or TU430).
5.Select the file to be uploaded. It will automatically be copied to the correct category.
6.In the Lens Compensation now select Activate best compensation.
7.Close the Laser Unit Settings dialog.
