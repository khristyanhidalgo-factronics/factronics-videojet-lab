Lens Hazard
The laser system contains optics constructed from Zinc Selenide. When broken into
small pieces or exposed to acidic conditions, they may give rise to harmful products.
In normal use however, the laser optical components are not considered to be
hazardous.
In the event that a laser optical component is damaged in any way, the material and
any packaging must be treated as hazardous waste and disposed of accordingly.

Optex Dual Detector
Dual detector accessory detects the speed of the product and automatically
adjusts the line speed set in laser for each separate product. This allows for
a variable speed belt and for users to move the laser from line to line with
the greatest of ease.
Considerations:
• Gap between products: Minimum 40 mm gap
• Constant belt speed: Changes in speed while product being sensed will lead to
inaccurate placement.
• Material reflectivity : The speed sensor sensitivity must be set correctly. For more IR
reflective products, a lower sensitivity is recommended. For less IR reflective products,
a higher sensitivity is recommended to minimize double trigger likelihood.
• Type of ambient light: Overhead florescent tube or LED office lighting, no direct
intense sunlight or incandescent lighting onto front of sensors.
• Product Shape: The line speed sensor works by detecting a difference between
nothing being there (low amounts of infrared light reflected back into the sensor) and
something being there (large amounts of infrared light reflected back). The sharpness
of that transition is provided by the shape and material of the item to be printed onto.

Optex Dual Detector – Product Shape
Strong sharp edge
This is the best shape for marking placement results.
Soft/rounded/draft edges
These products will require more adjustment of the sensitivity value
and alterations to the nominal marking offset so that the marking is
placed in the correct position. Placement variability will also be larger
but is in general still perfectly acceptable.
Odd shapes
A higher sensitivity is likely needed to ensure that double triggers do
not take place. The item material should also be more reflective.
Gaps in product
This will lead to double triggers. A Product Detect and Encoder is
required. Do not use Dual Detector.

Digital I/ Os – Interlock & Shutterlock
• Both Shutterlock and Interlock circuits must be closed in order for laser to
fire.
• Wire safety switch based on desired behavior (typically choose only one):
• Shutterlock – Laser tube stays powered, but shutter closes to block any beam.
Better for applications where enclosure door is opened and closed frequently
and quick recovery is required. Approximately 500 ms delay after Shutterlock
closed (confirmation prior to launch).
• Interlock – Laser tube power removed and shutter closes. Preferred for mark
on the fly applications because safer, but longer recovery time after door is
closed. Approximately 5 seconds delay until Laser Ready .
Pin Direction Signal Polarity
4 IN Shutterlock In Active Low
16 OUT Shutterlock Out Bridge to Pin 4 to close Shutterlock
1 IN Interlock In Active Low
14 OUT Interlock Out Bridge to Pin 1 to close Interlock

2) USB at Bifrost board (only for reload/update of CMark; cannot use this
method for loading Bifrost if no CMark already installed) - CMark 4.11 or newer
only! USB plugged directly into USB port on Bifrost, not ports on TU4x0. Must use
TU4x0 for control; cannot navigate with PC with web browser to load from USB
connected to laser.
3) Web Interface via PC with Web Browser – slowest
File requirements when loading from USB at Bifrost:
• Must be file type .zip
• Name must start with “CMark” (example: CMark_4.11_rev.9999)
• File must be saved inside folder named “TCS” on USB (TCS in all capital letters)
Note: Loading CMark via USB currently only supported for Bifrost board

3210 CMark Backup
CMark backup contains all Customer Data as well as the CMark
operating system. Backup process can take 10 - 30 minutes depending
on method used.
• CMark backup does not contain System Database (laser configuration such as
model, head type, IP address etc.) A backup of the System Database can be done
separately as this is contained in different location on Bifrost.
• Complete Laser Image backup can be done more frequently and saves Customer
Database (includes Jobs, Fonts, Mark Settings, etc.).
Preferred Method (in order):
1) TCS+ via PC with Web Browser – fastest; saves backup to Downloads
folder on PC unless web browser settings have been changed.
2) USB at Bifrost board – saved in folder on USB called TCS (if such folder does
not already exist). USB must have at least 600 MB of free space available.
3) Web Interface via PC with Web Browser – slowest; creates backup in
RAM on laser and then can be downloaded to PC Downloads folder.
Note: Backup of CMark via USB currently only supported for Bifrost board.

Rescue Stick for Bifrost Board
“Rescue Stick” is a USB (you provide) to which a PlexMark.img file is written with a
software to make the USB a bootable device. The . img used is the same as the
manufacturer - installed software called PlexMark that is on new Bifrost boards
(manufacturing or spares).
o Rescue Stick first wipes out the CMark on the Bifrost board and then loads PlexMark .
o After PlexMark is loaded then still need to load CMark.
o Rescue Stick does not erase System Database (model, head, lens, serial number, etc.)
Use PlexMark 1.11 for 3210
• Write PlexMark to USB using freeware called Rufus (Files on Sharepoint )
• Insert Rescue Stick directly into Bifrost USB; do not use TU4x0 USB!
• Boot with Rescue Stick. Laser goes to Standby when complete.
• Remove Rescue Stick and then reboot.
-- If boots, then load CMark using PC with web browser connected to TCS+. Loading via
PC connected by Web Interface also possible, but slower. Loading via USB at Bifrost not possible
first time after Rescue Stick used. Loading from USB only works when CMark exists already.
-- If laser will still not boot after Rescue Stick, please try Rescue Stick again. Do not
replace Bifrost until tried Rescue Stick at least two times.
Previous PlexMark versions only allowed loading of CMark via Web Interface. If cannot load
CMark via TCS+ then try Web Interface.

Inlet Filter Mat – Preferred Orientation
Air Inlet filter (side of laser) needs to be installed with the fluffy side toward the
outside and the stiffer side toward the inside. This way, large particles can be caught in the
fluffy region while smaller particles will be caught on the more densely packed side. If it
were mounted the other way around, the efficiency of the filter would still be the same, but it
would get clogged faster.
Air outlet filter (rear of laser) does not have a preferred orientation.

5. Troubleshooting

Normal System Operation
• Power on from main power button
• AC Voltage to power supply
• 48VDC to Bifrost board
• Blue Light on Keypad
• On/Standby button pushed
• White LED starts flashing
• Power (current) and signals from Bifrost to galvos
• White LED on solid
• Keyswitch armed (button press)
• Bifrost verifies key, shutter, interlock/ shutterlock
• 48VDC from Bifrost to laser tube
• Shutterlock open removes marking signals
• Interlock open removes 48 VDC to laser tube

Power On Issues
Symptom: No LEDs illuminated on keypad
Check:
• Mains cable connected (at rear of laser and to wall
outlet/power source)?
• Main power rocker switch on?
• Mains VAC at power supply?
• If no voltage replace internal mains cable.
• Measure VDC at Bifrost board System
Power terminals.
• If 48VDC present: exchange Bifrost board.
• If 0 VDC present: exchange power supply.

Boot Issues
Symptom: White light on keypad does not start to flash or flashed for
more than 3 minutes and does not stay on solid.
Remedies:
• Use Rescue Stick ( PlexMark 1.11) to wipe board and then load CMark .
- Rescue Stick procedure removes all system files and loads only web interface
software (no CMark or TCS+). New Rescue Stick image and directions
- After Rescue Stick ( Plexmark 1.11 and newer) then you must load CMark via either
TCS+ (web browser only) or Web Interface. Do not use TU4x0 USB ports to load
CMark!! Previous Rescue Stick image (for Chameleon) would not allow for loading
of CMark via TCS+. Had to first load CMark via Web Interface first.
- System Database (model, lens, serial number, IP address, etc.) are not erased with
Rescue Stick, but will not be correct/visible in Web Interface until after CMark is
loaded.
• Replace Bifrost board if still cannot boot laser. Only replace after at
least 3 attempts at recovering with Rescue Stick.

TU4x0 Does Not Display TCS+
Issues:
• TU4x0 does not display TCS+ and instead shows something like this:
Possible Causes:
• CMark not loaded on Bifrost board.
• PlexMark (manufacturer level software) not loaded on Bifrost board.
Remedies:
• Load CMark via TCS+ through PC with web browser (if Plexmark 1.11 or newer
installed) or Web Interface on PC with web browser.
• Use Rescue Stick on Bifrost board (loads PlexMark ) and then load CMark.

Fan Fails to Run
Symptom: System boots, but fan does not operate
Possible Causes:
• Check fan connection at Bifrost board
• Measure 48 VDC between fan connectors
- 48 VDC present: exchange fan
- 0 VDC present: exchange Bifrost board

Laser Overtemperature
Issues: E00202 Laser Overtemperature error occurs
Check:
• Is ambient temperature over 40 degrees C
• Is fan running
• Are filters clogged (side and rear of laser)
• Is laser tube clean/dust - free

Beam Shutter or Galvo Missing Errors
Issue: E10302 Shutter does not stay open or E10303 Shutter does not stay
closed error occurs.
Issues: E09006 No X - Mirror connected or E09007 No Y - Mirror connected error
occurs
Check:
1) Reboot system.
2) Disable Leakage Protection in TCS+ > Main Menu > Laser Unit Settings >
Laser Configuration and then reboot system when prompted. If error continues
to occur after reboot then continue to step 3.
3) Ensure galvo connectors at Bifrost board are seated securely. Ensure laser unit
is completely powered down and capacitors have discharged and then reseat
connectors.
4) Replace Bifrost/Marking head

Galvo Overcurrent Errors
Issues: E09004 Marking head: Overcurrent X mirror or E09005 Marking head:
Overcurrent X mirror error occurs
Check:
1) Check that Mark Settings are correct for the system and application. Reduce
Jump Speed .
2) Check that the Laser Position is correct in Line Setup.
3) Disable Leakage Protection in TCS+ > Main Menu > Laser Unit Settings >
Laser Configuration and then reboot system when prompted.
4) Ensure galvo connectors at Bifrost board are seated securely. Ensure laser unit
is completely powered down and capacitors have discharged and then reseat
connectors.

Marking Head Temperature
Issues: E09000 Marking Head: Temperature of Marking Head
Assembly Group Too High error occurs
Check:
• Is ambient temperature over 40 degrees C?
• Is fan is running?
• Are filters clogged?
• Reduce Jump Speed and/or increase gap between products

No Encoder/Trigger Detected
Issues: E10813 No Encoder Connected or E10814 No Trigger
Detector Connected error occurs
When Line Setup is set to look for encoder or product detect, but no
drain on 24V output on DIN connectors then error is generated.
Check:
• Line Setup – should encoder/product detect be enabled or is the
application static/indexing?
• Encoder or Product Detector is connected
• Verify wiring of Encoder or Product Detector to DIN connectors (3
pin and 4 pin DINs) if using alternate trigger source encoder
• Check I/O cable (internal cable from DINs to Bifrost board)

Interlock/ Shutterlock Issues
Symptom: Interlock Open or Shutterlock Open will not clear.
Verify wiring:
• Jumper plug in place (if nothing connected on Customer I/O)
• Interlock 24VDC being returned at pin 1 from pin 14
• Shutterlock 24VDC being returned at pin 4 from pin 16
