SOI is a simple, convenient and easy-to-use operator
interface program – combined with state of the art
touch-screen technology. It allows for fast job selection,
easy modification of marking code, and startup and
stop in just a few simple steps.
The SOI software is offered preinstalled on a color touch-
screen but can also be purchased separately as it runs on
any PC or PC-based machine interface under MS Windows
XP/Vista (e.g. OEMs). Upon start-up, it connects with the
laser system and can access the messages which are sto-
red in the laser database.
The SOI is usable with any ALLTEC laser marking system
apart from the ALLMARK series. The package is completed
with built in error prevention to further increase uptime.

SOI supports connections with up to 4 laser markers (with the addition of an Ethernet switch and standard
Ethernet cables)

Ordering Details
The SOI software comes pre-installed on a color touch-screen panel PC (Order Number AL-72830).
For customers who would like to use the same color touch screen interface for setup and programming, it is
also available with both SOI and SmartGraph software pre-installed (Order Number AL-72831).
These two Items are new Controller options (in addition to the Handheld) that may be included on a new equip-
ment order, or ordered separately to perform a field upgrade.
For customers that would like to install software on their own PC, both the SOI and the SmartGraph are availa-
ble on a USB thumb drive (Order Number AL-72840 for the SOI and AL-72845 for the SmartGraph). Please
note that while SmartGraph comes with a site license (one license per customer location), SOI software co-
mes with a machine license (one license per laser marking system is required).
The Mounting Bracket (Order Number AL-72835) is a universal device that allows the color touch screen panel
PC to be installed on any flat surface (vertical, horizontal or at an angle – e.g. machine panel, vertical post,
walls, etc.).

Marketing Bulletin 018-08
Bestelldetails
Die SOI-Software wird auf einem Farb-Touchscreen Panel-PC vorinstalliert geliefert (Artikelnr. AL-72830 ).
Für Kunden, die ein und dieselbe Touchscreen-Schnittstelle zum Setup und für die Programmierung nutzen
möchten, sind das SOI und der Smart Graph auch gemeinsam auf einem Farb-Touchscreen Panel-PC vorin-
stalliert erhältlich (Order Number AL-72831).
Diese beiden Zubehöre sind zwei neue Steueroptionen (zusätzlich zum G55 Handbediengerät), die Teil eines
neuen Laserbeschrifterauftrags sein können aber auch einzeln zu bestellen sind - etwa zum Aufrüsten im Feld
befindlicher Systeme.
Für Kunden, die die Software auf einem eigenen PC installieren möchten, sind das SOI und der SmartGraph
auf einem USB-Stick erhältlich, von wo aus sie installiert werden können (Artikelnr. AL-72840 für das SOI und
AL-72845 für den SmartGraph). Bitte beachten Sie, dass der SmartGraph auch weiterhin eine Kundenlizenz
fordert (eine Lizenz pro Standort ist ausreichend), das SOI aber eine Maschinenlizenz (eine Lizenz pro Laser-
beschrifter ist notwendig).
Der Haltewinkel (Artikelnr. AL-72835) ist ein universelles Gerät zur Arrettierung des Touchscreens auf allen
flachen Oberflächen (vertikal, horizontal oder im Winkel).
