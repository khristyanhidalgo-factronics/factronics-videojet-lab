Case# E01279 NAME Retain X Offset and Y Offset settings Type: Enhancement
on the connected laser.
Summary Description Required Software Version (or later)
Retain X Offset and Y Offset settings on the connected laser when the current job
is downloaded again
CCM CLARiSOFT
Not Applicable Not Applicable
Details:
Retain X Offset and Y Offset settings on the connected laser when the current job is
downloaded or pulled from an external database again.
This feature is enabled through the Clarity Configuration Manager tool. To enable this
feature the setting: Devices\Phds\1\Lasers\Laser\Configuration\RetainPrintPosition must
be set to 1.
Existing offsets will not be saved until an adjustment is made to them. Once an
adjustment has been made to either the X Offset or the Y Offset the settings will be
retained even if the Clarity Laser Controller is rebooted. Each job's settings will be
retained even after the same job has been reloaded from either CLARiSOFT or CLARiNET.
Offset settings are on a per job basis.
To disable this feature set the RetainLaserPosition parameter to 0.

Case# E01280 NAME Ability to correctly read SD Cards Type: Enhancement
formatted by Windows10
Summary Description Required Software Version (or later)
This fix resolves escalation TS2002979941 (Version One entry B-08353 Comet
Resetting IP Address After Re-power)
CCM CLARiSOFT
Not Applicable Not Applicable
Details:
Reports were received of CE6 CLARiTY printers resetting their IP Address to default
values after a power-cycle.
Root Cause was found to be how the SD Card had been formatted.
It was discovered that Microsoft had changed the way formatting partitioned SD cards
between Windows7 and Windows10 Operating Systems.
Windows 7 writes a partition type of 0x06 and windows 10 writes 0x0E when formatting
the card.
CE6 CLARiTY did not read Type 0x0E formatted cards correctly in the boot sequence,
which would result in an IP Address reset on power-cycle.
This is now resolved by an update to the Operating System and CE6 CLARiTY printers no
longer lose their IP Address after a power-cycle.

Case# E01317 NAME Improvements to 'Print Position' Type: Enhancement
Parameters
Summary Description Required Software Version (or later)
This is an enhancement to Case # E01279
CCM CLARiSOFT
Not Applicable Not Applicable
Details:
This release includes Improvements to the retention of 'Print Position' Parameters.
There is now a third method of retaining print setup parameters in CCFG behind:
Devices\PHds\1\Lasers\Laser\Configuration\RetainPrintPosition
This is a further enhancement to Case # E01279.
0: "Rest On Job Download".
X Offset, Y Offset, X Scale, Y Scale and Rotation are saved in the Ciff file when altered
on the CLC interface. These changes are lost if the job is downloaded again, or changed
for another job.
1: "Job Name Specific, Retain X and Y Offsets".
X Offset, Y Offset are stored against the Ciff File Name when altered on the CLC interface
These parameters will be retained for individual jobs, even if the same job is re-
downloaded and re-selected.
The Third (new) option is.
2: "All Manual Settings Retained".
X Offset, Y Offset, X Scale, Y Scale and Rotation are saved as 'Global' parameters when
altered on the CLC interface.
Therefore, these settings will be applied to all jobs and retained even if the current job
selection is changed or jobs are re-downloaded or if the CLC or laser are rebooted.
Further changes to the settings using the CLC user interface (Home Screen/Print Position
button) will be remembered in the same way.
B-08439 "Extending the X-Y, Scale and Rotational offset selection option with Clarity
Config/Clarinet/Clarisoft" is now resolved.

Case# E01355 NAME New 'Local' Markset Control Ability Type: Enhancement
Summary Description Required Software Version (or later)
This resolves Version One entry B-08581 Enable mark sets to be controlled
locally in the CLC
CCM CLARiSOFT
Not Applicable Not Applicable
Details:
Previously, whenever a job was re-sent form CLARiSOFT/CLARiNET or re-loaded via USB
stick any changes that the CLC had previously done to the Marksets in that job would be
overwritten.
In some circumstances this was undesirable.
Now, there is a new parameter in CCFG under Devices/PHds/1/Lasers/Laser/Laser
Configuration called 'Mark Set Control' which can be set to 'Remote' (Default setting) and
'Local.
When set to 'Remote' the Marksets will still be controlled by CLARiSOFT and Markset
behaviour will remain as it always has been.
When set to 'Local' further downloads of jobs from CLARiSOFT will not overwrite changes
to the Marksets that may have occurred at CLC since the last download.
Also, at the CLC user interface behind the 'Print Position' button there will be the ability
to 'Delete a single Markset' and to 'Delete all unused Marksets'.
Any Markset can be deleted, even Marksets associated with the currently loaded job..
If a Markset attached to a job still in the CLC database is selected for 'Delete a single
Markset' an "E6257 Selected Markset still used in a job(s)" WARNING will be presented to
the user.

Case# E01417 NAME CLC Counter Reset Enhancement Type: Enhancement
Summary Description Required Software Version (or later)
This allows the user to reset a counter at the laser.
CCM CLARiSOFT
Not Applicable Not Applicable
Details:
It was reported that when the laser reset the counter, the counter in the CLC was not
reset. On the next print trigger, the CLC sent down its existing counter value and
overwrote the value that was reset at the laser by external input (B-08894).
This software release now allows the laser to reset the counter value and that reset
propagate to the CLC.
NOTE: The new parameter, "CounterFromExternalPrinthead" under the "Imaging" folder,
in CLARiTY Configuration Manager, must be set from 0 to 1 to ensure the CLC resets its
counter value when the laser resets the counter.
For laser to control counter reset, set the new parameter,
"CounterFromExternalPrinthead" to 1.
For CLC to control counter reset, set the new parameter,
"CounterFromExternalPrinthead" to 0.

"CounterFromExternalPrinthead" to 1.
For CLC to control user-entered texts, set the new parameter,
"CounterFromExternalPrinthead" to 0.

Update Procedure
In order to update a machine with a previous software revision to the latest you should use
a USB memory device or the latest CLARiTY Configuration Utility.
a) To use a USB memory device, the CAB update file requires copy and pasting into a
‘CLARITYupdate’ folder in the root of the USB device. Insert the USB device into the port
on the printer and after a short while the screen may show an option to load new
software, depending on the printer settings in CCFG. If it does select ‘Yes’ then select the
required update, press ‘OK’ and follow on-screen instructions. If it does not, keep the USB
device in the printer and on the printers User Interface scroll to
Tools\Setup\Control\CLARiTY Update, select the required update and press ‘OK’ and follow
on-screen instructions.
b) To use the CLARiTY Configuration Utility, start the utility, and connect it to the printer
you wish to update. Ensure that the CLARiTY Configuration Utility has a valid TCP/IP
connection to the printer; this can be observed by the printer icon turning green, and the
"Active Connection" message being displayed in the status pane.
Right click on the name of the coder you wish to update and select the CLARiTY Update
option. Then locate the file with the same name as the part number above, and the
CLARiTY Update will then proceed automatically.
