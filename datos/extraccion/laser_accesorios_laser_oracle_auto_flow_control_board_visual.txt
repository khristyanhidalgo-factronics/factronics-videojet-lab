Auto Flow Control Board - Oracle Extractor .
Connection points are very straight forward.
Board is held in place by plastic neoprene nut. 5.5mm (8ea)
There is a black two pronged connection point on the board which is the sensor for the air flow. It has a small tube
attached to the prong that is closest to the board. It is a bit of a pain to put back on as it is a tight connection.
Check the original board and set the rotary switch on the new board to the same exact setting as the original.
After insta llation you will need to go back in and set your pump initial set point once you power up the extractor.
Please insure all connections are securely in place otherwise it will cause intermittent problems.
