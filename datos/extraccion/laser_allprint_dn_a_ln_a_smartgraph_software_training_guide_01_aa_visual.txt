Safety
The laser system must only be used for the treatment of material surfaces. The surfaces are locally heated by intensive
class 4 laser radiation and are modified thereby. These systems are mainly applied for marking of product surfaces (expiry
dates, batch printing, serial numbers, etc.).
The radiation produced by the laser system is of high energy and therefore improper use represents a danger to persons or
objects!
It is the policy of Videojet Technologies, INC to manufacture non- contact printing/coding systems and ink supplies which
must meet high performance and reliability quality standards. Videojet Technologies, INC enforces strict quality control
techniques to eliminate the potential for defects and hazards in its products.
The intended use of Videojet Technologies, INC Laser Marking Systems is to print information directly onto a product.
Use of this equipment in any other fashion may lead to serious personal injury.
The safety guidelines provided here are intended to educate all attending the presented course on all safety issues such
that they may install, operate, service, and maintain the subject printer (s) in a safe manner.

Electrical Safety Guidelines
This section explains the safety guidelines related to electrical power supply, electrical cables, fuses, bonding, and
grounding.
Electrical Power Supply
Personal Injury
Lethal voltages are present within this equipment when it is connected to the mains electrical supply.
Only trained and authorized personnel must carry out the maintenance work.
Personal Injury
Observe all statutory electrical safety codes and practices. Unless it is necessary to run the printer, dis -
connect the printer from the mains electrical supply before removing the covers or attempting any ser -
vice or repair activity. Non- adherence to this warning can result in death or personal injury.
Personal Injury
A high AC voltage is present at the inverter and backlight. Extreme caution is required when diagnosing
failure in these areas.
Electrical Cables
Personal Injury
Use only the mains power cable supplied with the printer. This cable must terminate in an approved,
three- pole, mains plug which has a protective ground conductor.
l The electrical power cables, sockets, and plugs must be kept clean and dry.
l For pluggable equipment, the socket- outlet must be installed near the equipment and must be easily
accessible.
Personal Injury
Always inspect the cables for damage, wear, corrosion, and deterioration. Make all grounding/bonding
connections void of areas of paint, ink build- up, and corrosion.

Bonding & Grounding
Personal Injury
The printer must be connected only to an AC power supply that has a protective ground conductor and
must be according to IEC requirements or applicable local regulations.
Personal Injury
Do not use the printer if there is any interruption in the protective ground conductor or if the protective
ground conductor is disconnected. The failure to follow this warning can cause an electrical shock.
Personal Injury
Always ground conductive equipment to an earthing electrode or to the building grounding system with
approved cables as per NEC standards in order to drain all potential static discharge. For example, a
metal service tray to earth ground.
Personal Injury
A resistance reading from the grounded service tray to the equipment chassis or mounting bracket
should be 0 to less than 1 ohm. A resistance check should be made using a safe and reliable ohmmeter
and should be done on a frequent basis.
Personal Injury
The PCBs contain static sensitive devices. A suitably grounded, antistatic wrist strap must be worn
when working on or handling PCBs.
Personal Injury
Always prevent static discharge from occurring. Use proper Grounding and Bonding methods. Only use
Videojet approved metallic service trays and ground cables.
Personal Injury
Always bond conductive equipment together with approved cables to maintain them at the same poten -
tial and minimize static discharge. For example, printhead to metal service tray.

SmartGraph Software Training Guide
SmartGraph Overview
SmartGraph software can be used to create files to be marked by Videojet lasers. The software can also be used to oper -
ate the laser itself and to control the marking process. SmartGraoh allows for different password protected user levels that
can limit the functions available for each of three user levels.
l File
l Laser Operation
l Template
l Configuration
File Tab
The File tab is used for file management such as importing and exporting files to/from SmartGraph, transferring files
between computer and laser, and connecting a PC to a Videojet laser system. This tab is also used to set defaults, such
as fonts, parameter sets, and product registrations, that allow for more customized and efficient job creation.
Laser Operation Tab
The Laser Operation tab is used to perform print functions including: selecting a template, starting and stopping the mark -
ing process, adjustment of placement of mark, and viewing errors and warnings.
Template Tab
The Template tab contains all functions necessary to design a Template. A Template is a file containing all the of the ele -
ments such as text, graphics, barcodes, etc. and their positioning. The Template tab is also used to access Parameter set -
tings that allow for marking on different materials.
Configuration Tab
The Configuration tab allows users to define settings for the laser marking system and the SmartGraph software program.
Contained within the Configuration tab are Product Registration settings which define the line setup including trigger
source and delays, encoder and fixed speed settings, and direction of line travel (when applicable). The tab also allows
adjustment of system date and time, language of SmartGraph software, password protection, and unit of measurement.

File Tab Terms
The following terms are used within the File tab:
l Template
File that contains the layout of the marking, e.g. text, logos (graphics), dates, times, serial numbers, fonts, etc. In
other Videojet products would be a Template would be similar to a message or a job file.
l Logo
A graphical element that can be added to a template. Logos must be imported into the database before they can be
used in a Template.
l Database
A file which contains all templates, fonts, logos, parameter sets, and product registrations. Though multiple data -
bases may be created and saved on a computer, only one database at a time may be open on the computer. The
laser system contains a database
l Parameter Set
A type of file contains settings to adjust the laser system to the respective material of the product. For example, a
parameter set contains settings for laser intensity and marking speed. which affect how deep the laser burns into
the material. Parameters sets can be adjusted through the Template tab.
l Product Registration
Type of file that contains all data necessary to detect a product and to trigger the marking process. Also includes
information on movement of the product and how that movement will be sensed.
Create Database
Databases can be created and saved to PC or on a network. Reasons for creating Databases including creating a space
to backup files from the laser or for creating messages offline for later transfer to the laser unit. A Database should be cre -
ated for backup of each individual laser.

Connecting to Laser
After creating an Edit Marking System file, or if applicable file already exists, you can connect to the laser by selecting the
appropriate file from Marking System drop- down menu.
If you have successfully connected to the laser you will see the following button and the right half of File tab screen will be
populated with file names.
Troubleshooting
If not able to complete connection to laser, try the following:
1. PC IP address must be compatible with IP address of laser. First three octets of PC IP should be the same as the
laser, but last octet must be different. Example: Laser IP is 192.168.1.1 and PC can be set to 192.168.1.87
2. Ensure the SmartGraph version is compatible with the CMark/QMark operating system installed on laser. If version
is not compatible then you will not be able to connect. CMark/QMark and SmartGraph version information can be
found in the laser web interface or in version.txt file on SD/MMC card in Smarties folder. Note: CMark versions older
than 3.4 will not show necessary SmartGraph version in version.txt file, but can be found in Web Interface in Boot
Logs tab. All other versions of CMark 3.4 or newer and all QMark versions will show necessary SmartGraph version

Disconnect from Laser
Before powering down laser system, or when connecting to a different laser, it is recommended to Disconnect through the
File tab before exiting SmartGraph or unplugging Ethernet.
1. Click the File tab at top of SmartGraph software.
2. Click Disconnect in the drop- down menu in upper right hand corner of File tab screen.
3. Wait for SmartGraph to sever the connection. Icon to left of drop- down menu will indicate when disconnected. Also,
no files will be shown below drop- down menu when disconnected.
It is now safe to exit SmartGraph and to power down laser system, if desired.
Possible File Corruption
Failure to disconnect properly before exiting SmartGraph or before unplugging Ethernet or
shutting down laser system can result in corruption of files on SD/MMC card.
Template Tab Tool Bars
Templates are individual files that contain all of the elements necessary to print such as text, graphics, barcodes. Within
the Template tab these files can be created or edited, but only User Level 1 and 2 have access to this tab if password pro -
tection is active.
Three main tool bars are available in the Template tab. The Symbol Bar is always available in the Template tab, but the
Tool Bar and Property Bar are only active and visible when a Template is open.

l Symbol Bar
Use the Symbol bar to create, edit, and save Templates. The Symbol Bar also allows individual objects to be
grouped/ungrouped and has cut, copy, paste, undo, and redo functions. Placement functionality is also available
through the Symbol Bar including a button used to move a selected object to the center of the marking field and but -
tons to move objects to the foreground or background with the Template.
l Tool Bar
Use the Tool Bar to create and insert objects into the marking field. Buttons to insert text, shapes, graphics, and
barcodes are available from the Tool Bar. Also available are information on the marking time for the open Template,

plate.
l Property Bar
Functions available through the Property Bar change based on the object that is selected. When no individual
object is selected then the Property Bar displays options available for the marking field as a whole. These function
include grid properties, measurement tool, and display jumps or points functions. When individual objects are selec -
ted, the Property Bar will change and display functions related to that specific object including placement within the
marking field, size of the object, rotation of the object and several options that are specific to the selected object 's
type. For example, with a linear barcode selected the Property Bar will show options for inverting the barcode (light
and dark) and selecting whether and where human readable characters appear.

Adding Variable Text to
Template
Many types of variable information may be added to a Template through the Text Format toolbar. Variable information
means that the information means that what is marked by the laser will change as the information changes. For example,
a variable date with a 60 day offset can be inserted into a Template. This will result in the laser always marking a date that
is 60 days from the current date on the product without the need to edit the Template.
Variable types available include:
l Date
l Time
l External Text
l Shift Codes
l Serializer

Trigger Settings
The Triggers are subdivided into Start Trigger, Consecutive Trigger, and Stop Trigger. The availability of individual trigger
settings depends on the selected trigger type and the product movement.
l Start Trigger
Defines the settings for the first trigger pulse. The marking is started by the first trigger pulse.
With the trigger set to Auto , the marking process is started by pressing the Start button on control panel of the laser
system or in SmartGraph Laser Operation tab.
To start the marking process via an external signal you can define whether the Rising or the Falling edge of trigger
pulse is to be used as trigger.
l Consecutive Trigger
Defines the settings for all trigger pulses following the start trigger pulse.
If the consecutive trigger is set to None , only the start trigger pulse starts a marking process and no following
pulses are accepted. Select None as the Consecutive Trigger when you want to generate a single marking.
If the Consecutive Trigger is set to Auto , the marking process is triggered internally and continuously. The marking
process is repeated with a certain frequency or after the product has moved a certain distance, depending on the
settings for product movement.
To trigger the marking process via an external signal you can define whether the Rising or the Falling edge is to be
used as trigger.
l Stop Trigger
Defines the settings for a trigger pulse that stops the marking process (e.g. the end of a cable or a stop signal from
an external control unit). The laser system remains ready to mark after a Stop Trigger pulse, which means that the
marking process will be continued if another Start Trigger pulse is detected.
If the Stop Trigger is set to None , then only pressing the Stop button on laser system or in SmartGraph | Laser
Operation will stop the marking process.
To trigger the marking process via an external signal you can define whether the Rising or the Falling edge is to be
used as trigger.
55
Rev AA

SmartGraph Software Training Guide
l Start Delay
Defines the distance until the marking process is started, which is the distance between the center of the marking
field of the laser system and the center of the marking on the product. After the trigger the product has to cover this
distance before it is in front of the marking head. If No Product Movement has been selected the Start Delay
defines the time between Start Trigger pulse and marking in milliseconds.
l Blocking
Defines the distance the product has to cover before the next marking can be started.
If No Product Movement has been selected the Blocking defines the time that has to pass after a Start Trigger until
a Consecutive Trigger is accepted. This value should be 70 - 90% of the pitch (product length plus gap between
products).
l Start Blocking
Sets the blocking time after the Stop Trigger pulse, where no external trigger pulses are accepted (debouncing) to
start marking.

Connect to the Web Interface
1. Before beginning work, ensure that you know the IP address of the laser system.
2. Set the PC's IP address so that it is on the same subnet as the laser. The first three octets of the IP address are the
subnet.
For example: If the laser's IP address is 192.168.1.1 then you set the PC address to 192.168.1.x (x can be any
number from 2 - 254. So your IP address could be set to 192.168.1.5. If the subnet portion of the address (e.g.
192.168.1) is not the same as the laser you will not establish a connection with the laser using any of the laser
software interfaces.
If the laser's IP address is unknown, Dip Switch 1 can be moved to the ON position. After power cycling the
laser the IP address for Ethernet ports will be set to 192.168.1.1.
3. Connect a crossover Ethernet cable to the desired PC/laptop and to the Ethernet port on the rear of the supply unit.
Alternatively, you can connect the laser side directly to one of the two Ethernet ports on the Chameleon board inside
the supply unit. This may be the case if a network cable were plugged into the standard Ethernet port and the optional
user interface port has a pinned connector.
4. Boot the laser (if not already booted). Do not attempt to connect until the laser has finished boot process and the
white light on the Supply Unit keypad has stopped flashing and is on solid.
5. Launch Internet Explorer program on PC. You may also use Firefox.
