AL-74453Modification Instruction
Safety Controller for Machine Integration
1 Sicherheitssteuerung zur MaschinenintegrationSafety Controller for Machine Integration
Bei ordnungsgemäßem Anschluss der Sicherheitssteuerung zur Maschinenintegration (AL-SP74335) erreichen die damit ausgerüsteten Lasersysteme den Performance Level "d" nach
EN-ISO 13849-1 oder die Sicherheitskategorie 3 nach der alten Norm EN 954-1.When the safety module for machine integration (AL-SP74335) is connected according to the
instructions all laser systems equipped with the safety module meet the requirements for theperformance level d according to EN-ISO 13849-1 or the safety category 3 according to the
previous standard EN 954-1.

LC100/3120/SL101/SL102AL-SP74335

GefahrVor Beginn der Arbeiten muss das Lasersystem unbedingt spannungs-frei geschaltet werden.
1.Drehen Sie den Schlüsselschalter in die Position »0«.Ziehen Sie den Schlüssel ab, um sicherzustellen, dass das Lasersystem
nicht eingeschaltet werden kann.
2.Sichern Sie die Datenbank in der »Datei«. Smart Graph-Software, Oberfläche
Eine detaillierte Beschreibung finden Sie in der Bedienungsanleitung derSmart Graph-Software.
3.Schalten Sie den Netztrennschalter aus.
4.Ziehen Sie den Netzstecker.
DangerBefore starting any work the laser system must be dead!
1.Turn the key-switch in the position »0«.Remove the key, in order to ensure that the laser system cannot be
switched-on.
2.Save the database in Smart Graph-Software, user interface »File«. For a detailed description see the manual of Smart Graph-Software.
3.Turn-off the main switch.
4.Disconnect the mains cable.
