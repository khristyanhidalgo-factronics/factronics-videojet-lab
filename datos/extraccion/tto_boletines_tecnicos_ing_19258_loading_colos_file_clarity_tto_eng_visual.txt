Loading Colos file by way of USB port in Clarity TT O Controller
T ool Needed:
Clarity Configuration
USB Memory Stick
When activating DCP to yes in Clarity Configuration, Colos files in their
original format (.itf) can be transfer into the printer via “USB memory stick
port “ .
Related Content:
For DCP emulation on Clarity printers, see Configuring DCP
Emulation (6530, 8510, 8520, 8610)
1. Enable DCP option in the printer . (YES)
2. Set CIMCOMMS port to 0. (this is needs to be “0”)
3. Disconnect all Ethernet cables.
From the Colos Software:
A ‘Print to File’ from CoLos software will need to be performed, to generate
the following (3) files extension:
xxxxx .itf
xxxxx.job
xxxxx.image

All the generated files need to be saved directly to the root on the USB
memory stick. It’ s recommended that it is best to have a memory stick that
is empty , when transferring the CoLos files.
Like we always say , do not ‘Save’ CLARiSOFT jobs to a USB stick, you
need to ‘Print to File’.
T ransfer files into Clarity Base Printer:
1. Insert USB stick in the USB port of the Clarity Base Printer .
a. When the USB is recognized the USB icon will flash on
the HMI
2. Select T OOLS-Setup-Control
3. Once the files are recognized “Imported Markem-Image Files”
icon will appears
4. Select the Import Markem-Image icon and answer the following
questions.
5. The files will be automatically transferred to the JOB folder
