To operate the software properly the following hardware and software requirements have to bemet:

1.2 Installation
NoteIf the PC is to be connected directly to one laser system the connection mustbe made using a crossover ethernet cable.
If the PC is to be connected to several laser systems the connection must bemade using a reliable Gigabit switch of industrial quality.
If the DataMaster software is used with several laser systems, it is expres-sively recommended to run the laser systems in a separate subnet via a dif-
ferent network card or network switch and not via the home network.
Important: Within this subnet, only the laser systems should be availablewhich are currently used with DataMaster software!
The cables which are used should have industrial quality, preferably CAT-7.
No other software (including antivirus software, automatic updates) shouldrun on the same PC as DataMaster software, neither should an external
operating panel (Handheld) be connected.
Please proceed as follows to install the DataMaster software:
1.Insert the USB stick (dongle) into the USB port of the PC.
2.Open the USB drive in the Windows Explorer.
3.Start the setup.exe and follow the instructions of the Install wizard.
ImportantThe USB stick (dongle) is to be connected PC and must not be removed from the PC after the installation or during ofconstantly to the USB port of the

The data are to be supplied in the following format:
File types
The file types *.dat are the standard marking data files. These files containthe data sets which are to be marked. They are indicated by a data icon.
The file types *.oob are the Out-of-band marking data files. These files con-tain the data sets which defined with the standard data files are to be com-
bined and marked. They are indicated by a crown icon.
The file types *.exl are the exclusion list data files. This file contains thedata sets which are not to be marked. The DataMaster software checks the
available standard marking data files to indicated by a filter icon.the exclusion list data files. They are
First the exclusion list data files must be assigned to the campaign, then Out-of-band markig data files, and, finally, general data files..
NoteThe format of the *.exl and *.oob data files is to be identical with the formatof the used *.dat data files.
Format and Name of the data files
The following naming conventions apply: Name.XXX.YYY.[ZZZ]
XXX can be dat,oob or exl
YYY can bexls,txt, xml or csv
ZZZ can be pgp,zip or zip.pgp and is optional
Example: Standard data file: Olympiade.dat.xls.zip
Out-of-band data file: Olympiade.oob.xls.zip
Exclusion list data file: Olympiade.exl.xls.zip

User Interface
The data are to be supplied in the following format:
File types
The file types *.dat are the standard marking data files. These files containthe data sets which are to be marked. They are indicated by a data icon.
The file types *.oob are the Out-of-band marking data files. These files con-tain the data sets which defined with the standard data files are to be com-
bined and marked. They are indicated by a crown icon.
The file types *.exl are the exclusion list data files. This file contains thedata sets which are not to be marked. The DataMaster software checks the
available standard marking data files to the exclusion list data files. They areindicated by a filter icon.
First the exclusion list data files must be assigned to the campaign, then Out-of-band markig data files, and, finally, general data files.
NoteThe format of the *.exl and *.oob data files is to be identical with the formatof the used *.dat data files.
Format and Name of the data files
The following naming conventions apply: Name.XXX.YYY.[ZZZ]
XXX can be dat,oob or exl
YYY can bexls,txt, xml or csv
ZZZ can be pgp,zip or zip.pgp and is optional
Example: Standard data file: Olympiade.dat.xls.zip
Out-of-band data file: Olympiade.oob.xls.zip
Exclusion list data file: Olympiade.exl.xls.zip
