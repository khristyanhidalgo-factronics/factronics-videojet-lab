Create a Rescue Stick
The following procedure details installing the Rescue Image to a USB memory stick.
Rufus (The Reliable USB Formatting Utility, with Source) is a free and open- source portable application for Microsoft
Windows that can be used to format and create bootable USB flash drives or Live USBs. Other software tools may also
be used, but are untested. It is important that a software tool is used to create a bootable drive and that you don not just
copy and paste files onto the USB drive.
Requirements for creating Rescue Stick
l
USB 4GB or larger
l
Plexmark 1.14 or newer (.iso file type)
l
RUFUS 3.10 or newer, or other software capable of writing the Plexmark image to the USB drive.
The following procedure uses RUFUS, but other software for creating bootable media may be
used, though only RUFUS has been tested.
1. Download both PlexMark 1.14.zip and Rufus 3.10.zip. Contact Videojet Technical Support if you do not have
access to the download locations.
