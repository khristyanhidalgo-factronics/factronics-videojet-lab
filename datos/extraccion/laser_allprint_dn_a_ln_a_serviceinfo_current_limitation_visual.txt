Service Information

AchtungIm Allprint Service Monitor gibt es keine Strombegrenzung!
Wenn der eingegebene Stromwert den zulässigen Wert der eingebautenPumpkammer überschreitet, kann die Pumpkammer zerstört werden!
Dies gilt für die Versionen 1.1 bis 1.3 des Service Monitors.
Achten Sie darauf, dass der zulässige Stromwert für die im Lasersysteminstallierte Pumpkammer eingegeben wird.
AttentionThere is no current limitation in the Allprint Service Monitor!
If the current value entered exceeds the admissible value of the installedpump chamber the pump chamber can be destroyed!
This applies to Service Monitor versions 1.1 to 1.3.
Make sure to enter the admissible current value for the pump chamberinstalled in the laser system.
