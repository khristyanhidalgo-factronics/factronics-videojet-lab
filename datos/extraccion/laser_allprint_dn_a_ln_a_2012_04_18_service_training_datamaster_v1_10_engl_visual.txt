Terminology
• Data Lens Technology: The activated cell increases, other cells are reduced.
• Initial Screen: General settings in DataMaster.
• Laser Screen: Opens when one or more lasers are dragged & dropped into a campaign.
• Out of Band Data (OOB): Winning codes (symbol: crown).
• Exclusion List Data (EXL): Data set which is not to be marked (symbol: funnel).
• General Data File (DAT): Normal data set which is to be marked (symbol: data icon).
• Fragment Assignment: In the data processing configuration data fragments and text
variables, can be assigned by drag & drop.
• Traceability: DataMaster is writing LOG - files in order to track, if and when a string or
an activity was carried out.

Data Order
• It is very important, to keep the following order, while uploading data to a campaign:
1. Exclusion List Data .EXL (if desired – not a must).
2. Out of Band Data .OOB ( if desired – not a must ).
3. Normal Data .DAT

Data Master Service Training 9
20.04.2012

Naming Conventions
• The Format of files, which contains the variable data, must fulfill the following naming
conventions: Name.xxx.yyy.[zzz]
xxx is the comparision between normal data and exclusion list or out of band data
(can be dat, exl or oob).
yyy is the file type and can be xls, txt, xml or csv.
zzz is optional and can be zip, pgp or zip.pgp
Data Master Service Training 10
20.04.2012

Information
• Dynamic logos can only be marked, when the selected font contains logos.
DataMaster can not display these logos, but rather the Unicode/Ascii - value.
Apart from that, only static logos and graphics, which are already part of the
template, can be marked.
• DataMaster is allways opening in full screen mode. Users can leave this mode,
by using the short keys (ALT+TAB), in order to change to other windows.
• A browse button, will possibly be implemented, in order to select the path for
data, more convenient.
• While a laser is in error state or no longer ready to mark, the other laser systems
are still marking. This behaviour is regarding the DataMaster specification.
It‘s recommended to use the output error of the laser, in order to stop the
periphery of the customer.
