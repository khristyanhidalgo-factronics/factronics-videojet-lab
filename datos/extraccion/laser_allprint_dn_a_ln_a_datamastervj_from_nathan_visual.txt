Datamaster – what is it?
• DataMaster is an intelligent program for the balanced
distribution of data – such as promotional or lottery codes –
from source files to up to eight Videojet laser marking
systems. The software is perfect for highly sensitive
applications such as lottery and on pack promotions requiring
data security and demanding ultimate operator ease - of - use.
• DataMaster is a real win - win graphical user interface
program : It helps users to reduce code errors and waste,
and increases uptime while quickly marking consumer
packages with winning contents.
Confidential Internal Use Only

Datamaster Main Features
• Clear and Intuitive: Easy to Use and Monitor
• Easy to Setup
• Logging, Excluding, Winning
- Extensive logging feature tracks actions related to
campaigns, data import and printed data.
- Intelligent distinguishing between general data and winning
data.
- Visual code safety feature: If codes have been marked, their
respective data file is displayed grayed out, thus, they are
excluded for being marked a second time.
- Users can create special exclusion lists for data being
excluded for marking.

Datamaster - User Interface
• General software concept – Data lens technology
As for the DataMaster software, it is crucial that e.g. the status of the
individual lasers are always visible, the data lens technology concept
is going to be applied for the DataMaster software user interface.
By clicking into a cell, the UI morphs by slowly compressing all other
rows and columns and enlarging the active cell.
