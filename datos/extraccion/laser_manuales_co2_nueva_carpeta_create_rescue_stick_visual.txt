Creating a Rescue Stick
The following procedure details installing the Rescue Image to a USB memory stick.
1. Download both CMark_ Rescue_ 1.x.img and HDD Raw Copy Tool.exe . Contact Videojet Technical Support if do
not have access to the download locations.
