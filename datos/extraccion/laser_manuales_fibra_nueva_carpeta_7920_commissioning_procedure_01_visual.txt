16 Note the power reading and compare to the expected values.
Issues Noted
With a standard 90 or 190 degree straight through marking head , the system should achieve an output of 4.0 watts .
With a BTU or BUS installed , the system should achieve an output of at least 3.6 watts . This decrease is expected due to a
10% loss through the BTU or BUS.
Power output is as expected
Record the following in your Service Report :

Power output is NOT as expected
If output is less than 4.0 watts (3.6 with BTU / BUS) at 100% power correction, the system is considered an out of box failure.
Stop installation and order a replacement unit. If there are questions, contact Tech Support for further information.

19 Configure the laser system's Name and Country .
Issues Noted
Set the Country parameter correctly
The Country parameter establishes the frequency bands the cellular module (within the Digital Access Box) will use .
1. Go to the Main menu (wrench icon) and select Laser Unit Settings .
2. Select Laser Configuration .
3. Enter the Name of the laser. This name will be displayed in VideojetConnect Remote Service, wfx.videojet.com, and in the
tab at the top of the web browser window (when connected to TCS+).
4. Verify that the Serial Number, Model Number, Marking head, and Lens all match the traveler data sheet and serial number
plate.
5. Use the right hand scroll bar to scroll to bottom of right column and set the Country .
6. Press Save .
7. Reboot the laser when prompted.

21 If network connectivity is established, then register the laser with wfx.videojet.com and upgrade the laser to the latest version of
Issues Noted
CMark, if a newer version is available.
Note: Network connectivity is necessary for Over the Air Updates . If a connection is not available, then skip to the next step.
1. With a cellular or other Internet- facing network connection available:
2. Select Main Menu (wrench icon) | Laser Unit Settings
3. Scroll down to Software Download .
4. Press the Register Laser button. After a few seconds the Registration Status should show Complete.
5. Select preferred Upgrade Behavior (when updates should be installed).
6. After registration, look at bottom on Software Download to see if new CMark version available. Download will start auto -
matically as long as the keyswitch is open.
7. Reboot to install the CMark update.

22 If network connectivity cannot be established, then manually upgrade the laser to the latest version of CMark.
Issues Noted
1. Export the Printer Registration File (PRI) to your laptop by going to Main menu (wrench icon) | Laser Unit Settings |
Software Download | Export Registration File .
2. Upload the .pri from your laptop to wfx.videojet.com after locating the laser in the portal (search for its serial number).
3. Observe if a newer version of CMark is available (a yellow or red triangle will be displayed next to the laser's serial number /
friendly name).
4. Click the yellow triangle, red triangle, or the download button.
5. Go to Management | Product .
6. Locate and download the latest version of CMark (currently this step is required when manually upgrading a laser via
wfx.videojet.com).
7. After the new CMark version downloads to your laptop, connect to TCS+ and go to  Main menu | File Management .
Note: The best practice is to use a PC / laptop to load CMark (and SARs). The TU440 should not be used to load system files.
8. Press the Upload button and navigate to the CMark file to be loaded.
9. When the CMark update is complete, reboot the laser system and proceed.
10. In TCS+ select Main menu (wrench icon) | Laser Unit Settings | Software Download .
11. Press the Export Registration File button to get a new PRI file. Upload this second .pri file to wfx.videojet.com at the earli -
est opportunity. This step will complete the software upgrade process.

24 After the CMark update is complete, install any required SARs (if applicable).
1. Go to Main menu (wrench icon) | File Management and press the Upload button.
2. Locate the SAR file on your PC and upload it.
If the SAR is installed correctly then the laser system will prompt you to reboot.
Laptop / PC Required
SARs may only be installed via a laptop/PC and Ethernet cable, and must be formatted correctly.
l
System files such as CMark and SARs cannot be loaded via TU440.
l
SARs must be formatted correctly (.zip with startup.sh file at the root level of the .zip file).
l
If the laser system asserts errors upon upload, then ensure that there are no PDFs (user guide, instructions, etc.)
within the .zip file before trying again.
l
It may be necessary to unzip to get to the SAR package.

25 If it is safe to do so (if you are in an enclosed area or the laser is in a shielded area), then make a test mark.
Issues Noted
1. Create a new Job in TCS+.
2. Add a Test Pattern from Add list.
3. Select Marking Field .
4. Click in the marking field to insert the marking field pattern into the Job.
5. Press the Save button and Close . When prompted, activate the job.
6. Place an easy- to- mark substrate beneath the marking head at the working distance (check Laser Unit Settings | Laser Con -
figuration to identify the working distance).
7. Mark the pattern.
Was the mark created with no errors?
If errors are asserted, or if no mark is created at the correct focal distance (on a known easy- to- mark material such as
ink- coated cardboard) and with no accessories connected, then do not proceed with installation. A qualified engineer
must perform a power check to determine the emitted wattage.
26 Evaluate the print quality and determine if it is acceptable.
27 Create new backups after installation and before releasing the laser system to the customer.
1. Select Main menu (wrench icon) | Laser Unit Settings | System Database | Download to create another backup of the
System Database . You may then delete the original backup.
2. Create another backup of the Complete Laser Image under File Management. You may then delete the original backup.
