Exchange of the Beam Expander for LC100/3120
1 Exchange of the Beam Expander for LC100/3120
The following is required for exchanging the beam expander:
offset hex key 3 mm, 2.5 mm
2 protective caps for the beam expander
protective cap for the adapter sealing plate
1.1 Dismounting
DangerBefore starting any work the laser system must be dead!
1.Turn the key-operated switch in the position »0«.Remove the key, in order to ensure that the laser system cannot be
switched-on.
2.Save the database in Smart Graph-Software, user interface »File«. For a detailed description see the manual of Smart Graph-Software.
3.Turn-off the main switch.
4.Pull the mains plug.
1.Loosen the screws of the housing cover and remove the cover.
2.Remove the FM board (see instruction "Exchange of the FM board").
