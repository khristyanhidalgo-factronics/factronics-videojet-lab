Figure 1 - 3 CLARiTY controller power switch and Ethernet connection

use any of the Ethernet ports. The default IP address for the controller is 192.168.1.2.

CLARiTY® controller to the power switch to the ( I ) On position.

seconds, during which startup screen appears. On successful boot - up, the home page
appears (Figure 1 - 4 ).

2. 1 . 5.1 Print Position>>Mark Set Parameters
Figure 1 - 1 4 Print Position>>Mark Set Parameters
Marking head parameters
Jump speed defines the speed of movement of the laser beam when moving from one
stroke to the next. The laser is switched off during a jump. A typical value is 20000
mm/s.
Marking speed defines the speed of movement of the laser beam when marking the
product.
Jump - Delay defines the delay between the end of a jump and the start of the marking
process.
Mark - Delay defines the delay between the marking of individual vectors within a stroke.
Stroke - Delay defines the delay between the end of a stroke and the jump to the next
stroke.
Laser Parameters
Marking intensity sets the output power via the current value (with 100 %
c orresponding to the maximum power of the laser).
Pulse frequency can be set between 10 Hz and 65 kHz (YAG), 50 Hz to 20 kHz
(CO 2 ). Low values can be used to achieve a broken line.
On - Delay defines the delay between the attainment of the start position of a stroke and
the switching - on of the laser.
Off - Delay defines the delay between the attainment of the end position of a stroke and
the switching - off of the laser.
1 - 12

Filling parameters
Line width defines the actual line width for e.g. barcodes on the product.
This parameter highly depends on the material and is defined by measuring the line
width on the product (further information can be found in section "Barcodes" in this
chapter).
Overlap defines whether two adjacent lines overlap each other (positive
values) or if there is a certain distance between two adjacent lines (negative values).
This parameter refers to the entered line width and is stated in percent (further
information can be found in section "Barcodes" in this chapter).
Vector length
Min. vector defines the minimum length of a vector. Shorter vectors are not marked.
Max. vector defines the maximum length of a vector. Longer vectors are divided into
shorter vectors.

6. 1.3 Trigger Mode
Figure 1 - 54 Tools>>Setup>>Printhead>>Line Setup>>Trigger Setting
Trigger Settings
S tart trigger defines the settings for the first trigger pulse. The marking process is
started by the first trigger pulse.
With the trigger set to »Auto«, the marking process is started by pressing START on the
control panel of the laser system.
To start the marking process via an external signal you can define whether the rising or
the falling edge is to be used as trigger. If the connected system is a YAG laser, you have
the choice between three different input channels.
S tart delay defines the distance until the marking process is started, which is the distance
between the center of the marking field of the laser system and the center of the marking
on the product. After the trigger the product has to cover this distance before it is in front
of the marking head. If »No product movement« has been selected the start delay defines
the time between start trigger pulse and marking in ms.
Consecutive trigger defines the settings for all trigger pulses following the start trigger
pulse.
If the consecutive trigger is set to »None«, only the start trigger pulse starts a marking
process.
All following trigger pulses are not accepted. Select »None« whenever you want to
generate a single marking.
With the consecutive trigger set to »Auto«, the marking process is triggered internally
and continuously.
The marking process is repeated with a certain frequency or after the product has
covered a certain distance - depending on the settings for the product movement.
To trigger the marking process via an external signal you can define whether the rising or
the falling edge is to be used as trigger. If the connected system is a YAG laser, you have
the choice between three different input channels (usually the same channel as for the
start trigger).
1 - 30

6.1.3.1 Blocking
Blocking defines the distance the product has to cover before the next marking can be
started.
If »No product movement« has been selected the blocking defines the time that has to
pass after a start trigger until a consecutive trigger is accepted.
Stop trigger defines the settings for a trigger pulse that stops the marking process (e.g.
the end of a cable or a stop signal from an external control unit). The laser system
remains ready to mark after a stop trigger pulse, which means that the marking process
will be continued if another start trigger pulse is detected.
If the trigger is set to »None«, only the start trigger pulse starts a marking process. All
following trigger pulses are not accepted.
To stop the marking process via an external signal you can define whether the rising or
the falling edge is to be used as trigger. If the connected system is a YAG laser, you have
the choice between three different input channels.
Start blocking sets the blocking time after the stop trigger pulse, where no external
trigger pulses are accepted (debouncing).
6.1.3.2 Trigger mode
Figure 1 - 55 Tools>>Setup>>Printhead>>Line Setup>>Trigger Mode
Allows the user to select one of the following settings to determine the trigger for the
product marking:
External Rising : Select the trigger mode as External Rising if the trigger pulse is to be
given by the product that is entering the product detection zone.
External Falling: Select the trigger mode as External Falling if the trigger pulse is to be
given by the product that is leaving the product detection zone.
Internal Once : If Internal once is selected then marking is started on selecting the start
button.
Internal Continuous : If Internal Continuous is selected then marking is continuous and
can be stopped manually.
Note: The default value is External Rising.
Note: If the line direction is static, then all the four modes are available, else only
External Rising and External Falling modes are available.

6.6 Cleaning High - Power Laser Optics
The most common cause of laser damage is using a component without cleaning it.
Most users correctly assume that the manufacturer cleaned the optics properly. However,
under irradiation at the fluencies considered here, every cost - effective packaging method
contaminates an optic to an unacceptable degree. The first time you use a component;
clean it as described in Stage 3 below.
The most important consideration in cleaning optics is to avoid introducing more
contaminants than you remove. We recommend a three - stage process, but you should
apply stages 2 and 3 only if the first and/or second fail to eliminate the problem.
Handle optics only while wearing powder less latex gloves or powder less finger cots
(cleanroom compatible). After putting on the gloves, clean them with an appropriate
cleaning agent to eliminate any contamination from finger oils.
Always handle optics from the edge, not the surface.
To clean the laser scan lens you need of the maintenance kit:
• Lens cleaning tissues
• Acetone
• Air bulb
• Isopropyl alcohol
Risk: The laser system must be disconnected from the power supply before
starting with the activity.
1 - 54

1. Turn the key - operated switch in the position »0«.
Remove the key, in order to ensure that the laser system cannot be switched - on.
2. Save the database in Smart Graph - Software if you are not using auto save mode, user
interface »File«.
A detailed description can be found in the operating instructions of Smart Graph -
Software.
3. Turn - off the main switch.
4. Pull the mains plug.
Cleaning High - Power Laser Optics
Stage 1
In a clean environment use e.g. an air bulb or ear syringe to blow contaminants off the
optical surface. We do not recommend using compressed air or nitrogen lines because
these may contain their own contaminants (propellant, oil, etc.).
1 - 55

Stage 2
Place a lens tissue on the surface of the component. We recommend a soft lens tissue.
Place a drop of acetone on the tissue, wetting the entire surface, and then slowly pull the
tissue off the component. Note that a tissue moistened with solvent can absorb water
vapor from the atmosphere, thus becoming useless after about 20 seconds. Discard the
tissue after one use.
Stage 3
Fold a piece of lens paper one or more times to create a cushion so that pressure will be
applied evenly over the optical surface. Moisten the paper with the cleaning agent.
Holding the lens tissue with the index, middle and ring fingers, wipe across the
component in one smooth, straight motion, covering the entire surface. We advise against
holding the tissue in forceps, because they will produce an uneven pressure. If the
element is too large to be cleaned in one swath, clean half with a C - shaped motion, then
the other half in the opposite direction.
When cleaning mounted optics, you may need to fold the lens tissue into a triangle to
reach into the mounted edges.
