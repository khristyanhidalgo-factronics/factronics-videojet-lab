Installation Instructions
Preface
In the following instruction it is shown how to ins tall the TCL script at the laser. The
instructions refer to the usage of Windows XP, Engl ish. The instruction applies to other
languages and versions of Windows as well as to oth er operating systems
analogously.
Preparation
Switch off the laser. Remove the MMC card from it. Put the MMC card into a suitable card
reader which is properly connected to your PC.
Copy the files
Select the files sent by Alltec (TCL file and star tup.sh). Choose Copy from their context-
menu (right mouse button).
Browse the Customer-Folder on MMC
Open the location where the MMC of the laser is mou nted. (The drive letter may vary
depending on the hardware configuration of your PC. )
Browse path smarties/customer/ (relative to the m ount point of the MMC)
Paste Files into Customer-Folder
Paste the files from clipboard into the Customer-Fo lder. Replace existing files if necessary.
Afterwards don't forget to safely remove the MMC by Windows .
