3350 Product Features
• 30 - Watt CO2 laser system
• Marking Head Options: SHC 60, 100, 150 and new optional SHC - SF (Smart Focus)
• Wavelengths available: 10.6, 10.2 and 9.3 micron
• Up to 2,000 cps
• 90 degree and straight - out (0 degree) marking head options
-- Head can be rotated in 90 - degree increments with no additional parts
-- BTU/BUS still available for SHC60/100/150 heads
-- No BTU/BUS with Smart Focus Marking Head
• IP54 and IP65 variants
• Digital Access Box standard - Cellular and Wi - Fi; Wi - Fi only in some countries; no access box in some countries.
Cellular and Wi - Fi is country dependent and not available in all countries.
• Pilot Laser Optional (standard on SHC - SF marking head; optional on SHC60/100/150 heads)
• Focus Finder beam standard on SHC - SF marking head (not available on SHC60/100/150 heads; Focus
Finder only available with TCS+ user interface)
• Interface plates changed to include cable entry for Access Box. Quick Connector Plate and Standard
plate still have same connectors as previous, but now 1 additional.

CMark Loading Changes with CMark v. 5.x
• CMark must now be zipped with 7zip, though file extension will still be .zip
• Requires password to unzip (Not meant to be unzipped. Open archive to view files instead of
unzipping.) Intended to keep people from modifying CMark.
• To load CMark v. 5.x the Chameleon board must have Plexmark v. 2.x or newer installed
first (Rescue Stick). Only when Plexmark 2.x or higher is present will CMark 5 be loaded. Older
Plexmark such as 1.14 will not create correct partitions for loading.
Rescue Stick ( Plexmark )
➢ Use Rufus freeware to write PlexMark to USB (2 GB minimum)
Plexmark v. 2 is not backwards compatible for loading CMark v. 4. Need to be prepared with both
rescue sticks/ Plexmarks depending on which CMark you need to load!
➢ Rescue Stick ( Plexmark ) for CMark v. 4.x = Plexmark v. 1.x (3x40)
➢ Rescue Stick ( Plexmark ) for CMark v. 5.x = Plexmark v. 2.y or newer (3350)

CMark 5
General
• No Web Interface. All Web Interface functions now in TCS+ for improved security
• Support for SHC - SF marking head
• No RES necessary for VRS. Software which was on RES is resident on laser now.
• VRS support for SHC - SF features: view working distance offsets, layer information, etc.
• Over the Air CMark Upgrades (OTA) available (in conjunction with Digital Access Box).
• CMark package changes - compressed with 7z instead of zip, but still.zip file extension. Get an error now when try to
open with zip program. Also now need a password to open file. Updating CMark on laser remains the same.
• Date Change offset can be specified in minutes (TCS+ and SmartGraph )
• Expanded network settings including improved ethernet (DHCP and DNS available).
• Engineering Logs available via VRS.
• Can use NTP or get time from VRS . More time zones than previous.
• PLC ( EtherNet /IP and PROFINET) process data now include Job Working Distance to support SHC - SF 2.5D capabilities.
• ECC200 IDMatrix now supports many DMRE ( Datamatrix Rectangular Extension) formats (rectangular to fit better on
small spaces, but extension so can hold more data)
• New version Allprint Basic (v. 2.x) that includes command SetPositionWdOffset for SHC - SF
• Total and Used Memory now shown in TCS+>System Information; broken down by type of memory

Security Features TCS+
To improve security, TCS+ in CMark v. 5.x contains the following features:
• Upon install new passwords for default users must be created on first login (Administrator,
Supervisor, Operator). 2222, 1111 and 0000 used for initial login, but will be prompted to create new
password. (New password can be same as old password)
• User list not displayed and user must type in User Name to login ( you can turn this feature off to show
list in Users>Wrench icon>Login Settings ).
• Limits/rules on acceptable User names . Example: cannot create user called Admin or Admin1.
• Auto Logout on by default . Can disable, but even if disabled any Users with Administrator ROLE will
still be logged out after 5 minutes of inactivity.
• When no one is logged in then Job Preview is hidden (Can turn this off in Users>Login Settings)
• Enable/Disable HTTPS for TCS+ webserver and upload customer SSL certificates . HTTPS
enabled by default.

OTA and VRS Install Process
Pre - work
• Site survey: Check if cellular signal available in area where laser will be installed. If no cellular signal with mobile
phone, use CG100 site survey kit to see if CG100 is possibility to use cellular for VRS/OTA (Over the Air Updates of
CMark).
• OTA: Ensure Serial Number/laser is in WFX Portal
• VRS: Generate VRS Activation Code (code good for up to 30 days for unlimited number of printers/lasers, but only
valid for 48 hours after first use)
Installation (Cellular)
1) Login to TCS+ via TU440 or web browser on laptop (IP of laser) as Service user
2) Go to Main Menu (wrench icon)> Laser Unit Settings
3) Verify Serial Number
4) Set Name of laser (will be used as Friendly Name in VRS and in WFX Portal)
5) Set Country (sets Cellular frequency bands and carrier)
6) Press Save button
7) Reboot laser and allow some time for cellular to connect. Login again.
8) Ensure LTE cellular connection in Main Menu>Laser Unit Settings> Cellular . Allow 5 minutes if GSM for laser to find and
establish best connection. Must have LTE service or VRS cannot be connected via cellular.
*If Cellular is not available and OTA/VRS is desired, then set Wi - Fi or LAN for use with internet facing customer network (with
internal RES) or CG100 ( Cradlepoint /SAFE) to use traditional RES.
For CG100 connection: disable Cellular and Enable Wi - Fi (Main Menu>Laser Unit Settings>Cellular or Laser Unit Settings>Wi -
Fi) Connect to Videojet Wi - Fi SSID. Password is already programmed in the system when the laser sees Videojet Wi - Fi
available. See VRS Installation Manual for CG100 configuration.

OTA and VRS Install Process
After cellular, Wi - Fi or LAN connection established. Must have connection to internet to have Over the Air
Updates. If laser will have no connection, then disable automatic updates so doesn’t give confusing info
to customer.
Set OTA (Over the Air) update behavior (even if updates not desired):
a) Main Menu>Laser Unit Settings> Software Download
b) Register Laser with wfx.videojet.com portal by pushing Register Laser button. Laser Registered box
should appear after a few seconds.
c) With keyswitch open, allow 5 minutes to see if update if available.
d) If update available, install before proceeding by rebooting laser after screen shows Download 100% and
there is an Update button shown in gray under Available versions. Behavior is set to automatically install
update upon startup. Ensure update is installed and laser rebooted prior to completing next steps.
e) Return to Main Menu>Laser Unit Settings> Software Download
f) Disable automatic updates if SmartGraph customer or if pharma/med, or if customer preference
by unchecking box for “Activate Over the Air Upgrade”. Auto updates to the laser will result in a mismatch
of versions between laser and PC where SmartGraph is installed. This will lead to inability to connect
laser to SmartGraph . Pharma customers may have to revalidate line if laser CMark updates.
g) Select Upgrade Behavior from drop - down menu and set desired behavior (install updates on start - up,
shutdown or manually meaning the customer will be notified and must allow. This is similar to mobile
phone notification that update is available)
h) Press Save button.

OTA and VRS Install Process
To enable VRS: Connection via Cellular, Wi - Fi or LAN must already be configured. If using external RES or CG100 complete

1) Login to TCS+ as Service user.
2) Go to Main Menu>Laser Unit Settings> Remote Service
3) If LTE cellular or internet facing customer network available:
1) Checkmark Enable VRS box
2) Select Internal RES (if not already selected)
3) Enter Activation code (include dashes; not case sensitive)
4) If using customer’s WLAN or LAN then check box to “Allow VRS traffic over customer network”
5) Press Save button
6) Status should show Active and VRS icon at top of Home screen shown
If using CG100 or traditional RES (Configure CG100 or RES before performing the following steps):

5) If using customer’s WLAN or LAN then check box to “Allow VRS traffic over customer network”
6) Press Save button
7) Status should show Active and VRS icon at top of Home screen shown

Software Management in Portal (Laser Offline)
• If there will be no connection at laser, best practice is still to Register Laser, but will be a manual process similar to CI J. This allows for
dashboard view via WFX Portal to see installed software on laser and to quickly assess from WFX Portal if a new, mandatory or
escalation version of CMark is available or required.
• Registration is only done when the laser is connected. If offline (no connection) then registration process is one - way (upload o f PRI to
portal manually)
• All following steps are assumed using TCS+ connection via Web Browser and PC (cannot export PRI via TU430/TU440)
1) In Laser Unit Settings>Software Download, press the Export Registration File button.
2) In Export Registration File dialogue click on Export button. The PRI file is downloaded
to your Downloads folder on connected PC .
3) Connect via PC with internet connection to the Videojet Portal.
4) Search by Serial Number for the Laser and when found click on Upload PRI
5) After upload, the portal will determine if a new version of CMark is available or
required. (Red triangle= mandatory update available; yellow triangle = optional update
available and gray triangle = software update for laser has been downloaded, but no
new PRI has been loaded to portal to verify status). Download if desired or required.
6) Ensure downloaded package (CMark) name begins with “ cmark ” before loading via
TCS+>File Management. CMark file names must begin with “ Cmark ” (not case
sensitive) or file will be seen by laser as invalid file type.
7) Reboot laser to install new CMark.
8) Export new PRI (Laser Unit Settings>Software Download>Export PRI)
9) Load updated PRI to WFX Portal to close loop.
10) Cycle is complete.

What if… OTA and Manual Update
If OTA automatic updates are enabled and you are trying to manually update CMark through File Management,
then the following message may be displayed:
System having installed CMark, plus downloaded CMark from automatic updates, plus the version of CMark
you are uploading manually could make the laser run out of disk space. Warning dialog allows you to disable
automatic updates while loading. Can re - enable afterward.
If you select “Yes” from dialog, then the CMark downloaded automatically by the system will be deleted in order
to make room for your manual upload.

What if… Chameleon Replaced
If OTA automatic updates are enabled and you must replace a Chameleon board:
• CMark must be installed manually on new board. Spare boards do not have any CMark
installed and therefore are not programmed to look for wfx.videojet.com until CMark is
installed.
• System Database must be loaded or configured.
• Connection settings (Cellular, Wi - Fi, etc.) may need to be reconfigured even if a backup of
System Database is available. Some settings exist in System Database, but others are stored
as part of CMark. This reconfiguration may also be necessary after Rescue Stick because of
the divergent storage.
• New board means new MAC address so after configuring serial number, name, cellular, Wi - Fi
or Ethernet then: Register the laser onboard (if cell or other connection on laser) or download
PRI from laser and upload to the WFX portal manually.
*Process still in development; changes may occur before launch

Replace Smart Focus Head
The SHC - SF marking head is replaced with a complete new marking head and matched CP -
Light 3D A7 board. Additionally, the existing Lens Compensation file must be deleted first, and
then new Lens Compensation file must be loaded and activated .
New Lens Compensation file is not included with spare marking head. Must be downloaded
from Danaher Sharepoint in the FOBA - Alltec Service Page space. The files are organized by
serial number of the MARKING HEAD not the laser system serial number.
