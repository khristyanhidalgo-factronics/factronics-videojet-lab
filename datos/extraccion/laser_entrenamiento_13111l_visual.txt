Simple Printer P rotocol
For Lasers
1. Host Port C onfiguration:
TCP Client 1 , Port 20000
TCP Client2, Port 20002
2. Timeout :
None.
3. Basic format:
REQUEST: <Command>|<Parameters><CR><LF>
RESPONSE: <Result>|<Parameters><C R>< LF>
4. Parameters:
<TName> = Template Name (case sensitive)
<VName> = Variable Name (case sensitive)
<VSize> = Variable Data Size
<VData> = Variable Data
<VType> = ET,SN,DT or TM (ExternalText,SerialNumber,Date or Time)
<T Pos > = Template position (xOffset yOffset Rotation) eg. "10 20 180.0 00"
<TText> = Template text
<OType> = Object Type (Text, Barcode or IDMatrix)
<PState> = ON, OFF, ERR or CHK (ERR and CHK are readonly)
<Result> = ACK or NAK:Reason
< H ours > = Operating Hours ( 6509 )
<Clock> = Date and Time (2008 - 04 - 20T04:04:12)
<PCount> = Print Count
< L Size> = Lot Size
< LCount > = Lot Count
<ECode> = Error Code
< PDone > = ON or OFF
<SarNum> = SAR Number and Revision
<T I nfo > = Template Information (Mar kingTime VectorCount PointCount Ma rkingDistance
JumpDistance Height Width Xmax Xmin Ymax Ymin) eg. "129 10 321 161.77 35.91 12.04
56.89 28.45 - 28.45 6.02 - 6.02"
<LPwr> = 0 - 100
5. Commands:
Get Print State
RE QUE ST: GetPState<CR><LF>
RESPONS E: <Result>|<PState><CR><LF>
Set Print State
REQUEST: SetPState|<PState><CR><LF>
RESPONSE: <Result><CR><LF>
Get Print Count
REQUEST: GetPCount<CR><LF>
RESPONSE: <Result>|<PCount><CR><LF>

8 . Translate PState
The PState strings are defined in the \ smarties \ customer \ pstat e.t xt file located on the MMC card.
This is simple text file that can be edited to change the default PState strings as required by your
application. To translate these states, edit only the text within the quotation marks for each state.
