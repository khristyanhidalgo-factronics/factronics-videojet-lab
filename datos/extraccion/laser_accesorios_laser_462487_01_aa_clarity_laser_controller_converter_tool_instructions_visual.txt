Introduction
The Converter Tool allows the user to convert the messages created for the
laser systems to CIFF files for uploading to the CLARiTY
®
The tool takes the Laser XML messages directly from the laser system and laser controller.
converts them to CIFF files. The files will be stored in a location specified by the user.
The required steps involved in converting the messages are as follows:
1Installing the Software and supporting files (refer How to Install the
Converter Tool on page 1 ).
2Converting the messages from .xml format to .Ciff format (refer
How to Convert the Messages on page 4 ).
3Loading the messages to the controller (refer How to Load Messages
to the Controller on page 6 ).
The following optional step allows you to preview the converted messages before loading to the controller:
 Refer How to Prepare the CIFF Files for Importing on page 5 .
