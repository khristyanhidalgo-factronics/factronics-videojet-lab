1.5 Uploading Calibration Files
1.Log into TCS+/FOBA Go as "Service".
2.Go to Global Settings and select Laser Unit Settings.
3.Select Lens Compensation and select File Management.
4.In the File Management dialog select Upload and navigate to the USB stick containing thecalibration file (on the connected Laptop, PC or TU430).
5.Select the file to be uploaded. It will automatically be copied to the correct category.
6.In the Lens Compensation now select Activate best compensation.
7.Close the Laser Unit Settings dialog.
