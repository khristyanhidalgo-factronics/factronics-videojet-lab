Installing Wireshark
Videojet engineering has created a custom version of Wireshark that can filter and show
specific Videojet protocols (ESI, WSI, VRS, etc.) that are not available in the standard version
of Wireshark.
Note that the public release of Wireshark is on version 2.x, but the custom Videojet release is
using version 1.x. Disable/decline any automatic upgrade prompts.
1. Download the Videojet custom version of Wireshark-win32-1.12.6.
2. Run through the installation, accepting all defaults, including installation of WinPcap.
