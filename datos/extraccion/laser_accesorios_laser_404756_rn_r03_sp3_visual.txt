Case# E01188 NAME ZJF support added Type: Enhancement
Summary Description Required Software Version (or later)
ZJF Job Files Can Now Be Imported from USB
CCM CLARiSOFT
Not Applicable Not Applicable
Details:

CLARiTY printers using a USB memory device. ZJF files may be placed in the 'Jobs' folder

Case# E01190 NAME 7810 Q-Switch minimum value Type: Enhancement
enhancement
Summary Description Required Software Version (or later)
Q-Switch now allows values down to 2µs
CCM CLARiSOFT
Not Applicable 4.510 SP7
Details:
With Previous revisions of software, Q-Switch parameter was capped at a minimum value
of 9µs.
Now, values are allowed down to 2µs, and can be modified in the User Interface.
Note: CLARiSOFT 4.510 SP7 (or newer) will be required to create jobs with Q-Switch
values of less than 9µs.

Case# E01223 NAME Added Hexadecimal Data Format for Type: Enhancement
QR Barcodes
Summary Description Required Software Version (or later)
Added the capability of including hexadecimal data format for QR Barcodes for
laser printers
CCM CLARiSOFT
Not Applicable Not Applicable
Details:
The capability of including the hexadecimal data format option for QR Barcodes for laser
printers has been added. This enhancement will accept data up to the length specified
in the QR barcode specification.
NOTE:
Merged fields are not supported, fixed text must be added directly to the QR barcode.
It is recommended that only binary data cited in the defined section of ISO IEC 8859-1 is
used.

Case# B01211 NAME Restore All Jobs fix Type: Bug Fix
Summary Description Required Software Version (or later)
Fix for restoration of all jobs at once (that contain logos)
CCM CLARiSOFT
Not Applicable Not Applicable
Details:
Previously, if a number of jobs were stored in the Jobs folder on a USB stick that
contained logos, and all were restored to the printer at the same time (by pressing
'Restore All Job') then only the logos in the first job were restored.
This could result in a number of jobs with missing logos.
This is now resolved and 'Restore All Jobs' now works as expected if they contain logos.

Update Procedure
In order to update a machine with a previous software revision to the latest you should use
a USB memory device or the latest CLARiTY Configuration Utility.
a) To use a USB memory device, the CAB update file requires copy and pasting into a
‘CLARITYupdate’ folder in the root of the USB device. Insert the USB device into the port
on the printer and after a short while the screen may show an option to load new
software, depending on the printer settings in CCFG. If it does select ‘Yes’ then select the
required update, press ‘OK’ and follow on-screen instructions. If it does not, keep the USB
device in the printer and on the printers User Interface scroll to
Tools\Setup\Control\CLARiTY Update, select the required update and press ‘OK’ and follow
on-screen instructions.
b) To use the CLARiTY Configuration Utility, start the utility, and connect it to the printer
you wish to update. Ensure that the CLARiTY Configuration Utility has a valid TCP/IP
connection to the printer; this can be observed by the printer icon turning green, and the
"Active Connection" message being displayed in the status pane.
Right click on the name of the coder you wish to update and select the CLARiTY Update
option. Then locate the file with the same name as the part number above, and the
CLARiTY Update will then proceed automatically.
