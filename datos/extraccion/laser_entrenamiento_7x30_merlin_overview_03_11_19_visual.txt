Electronics Power Supply (48VDC)
• 48 VDC (200W) PSU for everything except laser source.

plugged in.

channels (2) all being closed.

Power Distribution

Chameleon Board - MCIP

Chameleon Board – X28 (Power)
Default Connections:
Pin 01 (V) and 02 (GND) : 24V to fan and galvo enable
Pin 06 (GND) and 12 (V) : 48V to CP - Light board
Pin 10 (GND) and 11(V) : Power to Chameleon (48V) from electronics PSU
Pin 13 (V) and 14 (GND) : Feedback from laser PSU
External Power 12V/24V: Pins 07 (V) & 08 (GND): 12V/24V and GND
from customer to supply CI
Important :
While supplying external 12V/24V, the complete customer interface is potential
free! Also the connectors for incremental encoders and light barriers!
Laser Power Supply Control: Pin 13 - 14
The Chameleon Board monitors if laser voltage (24V) is switched to the beam source
External startup: Pin 3 - 5
Customer can boot the system remotely, by applying a pulse of 24V_STDBY here.
By using the autostart bridge on X28.3 and X28.5, the system boots up automatically, after
switching mains and never powers down after shutdown sequence (reboots). Ensure
system main power is removed before reboot or safety system reset failure will occur.
NO EXT 24V allowed!!

Safety Options
Standard – SPM (Safety Power Module)
• Shutterlock - No Performance Level
• Interlock (no special parts) – No Performance Level
• Interlock with specific parts - Performance Level „d“
• O nly if mechanical positive break interlock NC - contacts, single
screened interlock wires (cross wire short detection), and push button
manual reset button are used. Any deviation from this results in no
performance level.
• No possibility to add FASS
• Different SPM than on 3640 models!!
Optional – CPD3 + FASS
Following performance levels achieved only with mechanical positive break NC -
contacts and single screened wires (cross wire short detection)
• Performance Level „d“ for Door (Shutterlock)
• Performance Level „e“ for Emergency Circuit (Interlock with
manual reset switch)

SPM Only
SPM version with IEC C14 mains entry can carry 8 Amps maximum current (fused)
Three Ways to Wire for Safety:
Shutterlock (No Performance Level Rating)
• No rated performance level
• Use fused 24V outputs for Shutterlock on X9 as directed in sample wiring
Interlock (No Performance Level Rating)
• Wire using any MECHANICAL switch. Do not use solid state switch or
damage may occur to contacts in switch (capacitors that have high current)
• Can jumper reset switch if performance level not needed.
Interlock ( Performance Level “D”)
• Performance Level “d” only if wired exactly as directed AND using exact parts
(cable and switch) in sample wiring (Use Schmersal AZ 16 - 02ZVRK (min
contact load 12 V / 5 mA) switch and shielded cable )
• Must use 24V_fused output on X9 for Reset Switch to maintain Level D rating
and to avoid errors which will result in Interlock Open status even when closed
• Requires reset switch for Peformance Level “d” (use push button type).

SPM (Safety Power Module)
K1/K2: Interlock channel 1 and 2 (connected doors closed or jumpers in place)
K3/K4: Chameleon board (software/logic/shutter/emissions LEDs)
K5: Part of error detection circuit for Performance Level D (detects damage
to external wiring of interlock system)

SPM LEDs
LED Name Color
D5 Laser Enabled Green (ON) Laser is enabled (both Interlock circuits closed)
D6 Shutter Enabled Yellow (ON) Shutter is enabled (both Shutterlock circuits are
closed)
D7 Shutter Closed Blue (ON) Shutter is closed (“Shutter is Closed”=High)
D8 Shutter Command Blue (OFF) Close shutter command (“Open Shutter”=Low)
D9 Laser Power Red (ON) Laser power supply is on
Fuse (F1) – 1 Amp: Blows when too much current on interlock/ shutterlock to
detect damage of external wiring. Not a system power fuse.

CPD + FASS
- K1+2: Reacts on interlock circuit and switches off the laser beam source
(Driver = CPD/FASS) -- Interlock important
- K3: Reacts on a safety logic (when the signal ‘safe laser power on‘ is
missing, K3 switches off the laser beam source too) (Driver =
Chameleon). Shutter and emissions LEDs important.
- K4+8: No function on 7x30

Troubleshooting

No Power to System
❖ Symptom: No Lights on Keypad
Under normal conditions (power, but not booted) following should occur:
• Blue LED on ON/Standby button is lit
• 48V dc input to Chameleon board – X28.11 (48V) and X28.10 (GND)
• D47 (green LED) (48V) lit on Chameleon board
❖ If above are missing, check:
• Mains Power Supply
• Ensure Main Power switch in ‘On” position
• Mains Input connector – 2 x fuses
• 48 V dc supply
• Membrane keypad and cable
- Use Autobridge to start without keypad – Jumper X28.3 - X28.5 (Ensure power
to system disconnected after test or safety circuit reset failure will occur)
• Chameleon board

Unsuccessful Boot – Diagnostic Checks
Multi - Core Chameleon
Symptom: White light on, but not flashing (On/Standby button)
Symptom: White light does not stop flashing (On/Standby button)
▪ Did you wait long enough (big lag time)
▪ Check battery voltage. 2.7 Volts or greater?
▪ Use Rescue Stick to overwrite system software
▪ If boots after that, then load CMark
▪ If still won’t boot after Rescue Procedure then replace
Chameleon board

Laser Source Errors
Symptoms: Defective Element in Laser Supply
(E00211)
Steps:
• Verify X9 pin 3 has red wire (laser power) inserted
completely and X9 pin 13 has gray (laser ground)
inserted completely
• Verify 24V to X9 pin 3
• Relays on SPM/CPD3 may be worn out. SPM/CPD are
the switching element from the Chameleon’s view.

Safety System Errors
Symptoms: Interlock Open status and not able to clear
Steps:
• Verify both interlock circuits are closed
• Check wiring at door switch/emergency switch on customer side
• Verify connection at X9 pins 17 - 21 and 15 - 19
• Check fuse at X9
• If no FASS , then verify jumper from X9 pins 1 - 23 in place or reset
switch is installed and closes then opens following reset.
• If FASS installed, ensure reset switch in place X9 pins 1 - 23 is
normally open, then closes and opens again following interlock
open.
• Both interlock circuits must open/close at same time. Too much
time between open and close on circuit 1 and 2 results in Interlock
Open.

Safety System Errors
Symptom: Clicking noise while Interlock Open
Steps:
• System is designed for double pole switch (two
channel redundant interlock circuit). If only using
single pole switch and just replace one jumper
with switch then clicking noise will be heard. This
is a relay struggling to latch and this will do long -
term damage to CPD/SPM board.
• Use following wiring scheme with single pole
switch:
• X9 pins 17 - 21 install single pole
switch from pins 15 - 19
• Jumper pins 15 - 17 and 19 - 21

PROFINET

Industrial Protocols
• EtherNet /IP is primarily adopted in North America
• Standard offering for Allen - Bradley (Rockwell Automation)
• PROFINET is primarily adopted in Europe
• Standard offering for Siemens and GE PLCs.
• Decision based on:
• Customer’s current environment (is one already in place)?
• Real - time constraints – PROFINET has deterministic real - time
performance.
• The application (commands) support is equal for both PROFINET
and EtherNet /IP .

Pertinent Info
PROFINET
• Conformance Class: C
• Cyclic Rate: 250 us (microseconds)
EtherNet /IP
• Cyclic Rate not documented.
Both PROFINET and EtherNet /IP
• Star, Closed Ring, and Open Ring (daisy chain) topologies
supported
• Update of counter values is not done in real time, but updates
at least every 100ms.

Notes and Rules
• Process data is exchanged periodically, though
commands are not executed each time. This is done to
change the command ID to trigger next action.
• Command “ NoOperation ” must be sent before a new
command can be sent. Example: NoOP - Start - NoOP - Stop
• Exception to this rule: To trigger loading of field data,
these commands can be toggled: NoOP - LoadFieldDataA -
LoadFieldDataB - LoadFieldDataA …
• When “ NoOp ” is sent, the sender must check and wait for:
CommandRespons =“ CommandSuccess ” and
CommandExecuted =“ NoOp ”

Notes and Rules
• Only one command can be executed at a time. If a command
is in progress and a new one arrives, it will be postponed and
executed when the first one has been finished.
• When a command was executed successfully the Response
will be set to " CommandSuccessful " and the ID of the
command will be assigned to " CommandExecuted ".
• When a command failed to execute, Response will contain
respective error ID and " CommandExecuted " will not be set.
• Commands with an unknown ID will be answered with
"Unknown Command".
• " CommandInProgress " indicates the processing of
command and not the action.
• " CommandInProgress " will not be set for " NoOperation “ and
commands with unknown ID.
