SmartGraph Software
SmartGraph is a Job creation and laser interface software installed on a Windows computer, which
may be a Videojet Panel PC. Videojet customers Will often have SmartGraph in addition to an "on the
line" user interface solution such as SOI, TU4xO, G55 Handheld, or a CLARiTY Laser Controller. They
may also run SmartGraph directly on their Touch US HMI.
Figure I: SmartGraph software
TCS+ Software
Touch Control Software (TCS+) performs the following functions:
Generating and organizing jobs and parameter settings
• Configuring the Line setup
• Transferring data to the laser system
TCS+ software is accessed on a mobile device, PC, or a TU440/TU430 Touchscreen Monitor.
Simple Operator Interface (SOI) Software
The Simple Operator Interface (SOI) is a an HMI software that is usually installed onto a Videojet Panel
PC. Note that some people use the term "SO"' and "Panel PC" interchangeably, so it is
important to confirm which software is in use before proceeding with troubleshooting.

TU4330 and TU440 HMls
The TU430 or TU440 is an attached HMI with a stainless Steel case measuring 275 mm x 195 mm x 48
mm (10.83" x 7.68" x 1.9"). It has a Videojet logo badge in the middle above the display screen.
The power cable attaches at the top of the chassis.
Figure 3: A TU440 HMI.
Videojet Panel PC HMI
The Panel PC is a Windows Computer in the form factor of an HMI that can run TCS, SmartGraph, and
SOI Software Because of this flexibility, presence of a Panel PC in an application does not immediately
equate use of a specific software, however note that some people use the term "SO"' and "Panel
PC" interchangeably, so it is important to confirm which software is in use before proceeding
with troubleshooting.

Touch US TU420H HMI (Legacy)
The TouchUS is a touchscreen interface that looks similar to the TIJ430 and TU440 but has the legacy
T CS software, SmartGraph, or SOI onboard the HMI device itself. It is an attached HMI with a stainless
Steel case measuring 300 mm x 215 mm x 45 to 62 mm (11.812" x 21 5" x 1 77" to 2.44"). It has a
Videojet logo in the top right corner OR middle above the display screen. It has a single, stainless
Steel button in the middle below the display screen. The power cable attaches at the top of the chassis.
