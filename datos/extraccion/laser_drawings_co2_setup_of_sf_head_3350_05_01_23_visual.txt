Installation of Laser with SHC-SF Marking Head
Pre-Work:
 Ensure that samples have been run and that the applications have been approved for
the SHC-SF marking head.
 Do you have the Sample Report PDF with:
o Size Mode or Range Mode noted?
o Working Distances for each Job and, if multiple planes to be marked on same
product, are working distances for each plane noted?
 Did you download or have you received:
o Complete Laser Image or Database or individual Jobs created during sampling?
 Import Complete Laser Image or Jobs from Application Lab first before creating or
configuring anything in TCS+. Complete Laser Image import will overwrite any existing
Jobs, etc.
Installation
Follow general install process for unpacking, checking accessories and booting without errors.
The following procedure is specifically meant for the mechanical setup and Job setup on 3350
lasers with the SHC-SF (Smart Focus) marking head.
Steps:
1) Based on sample report results (PDF), select a product that was sampled and physically
adjust laser marking head distance to product based on sample results (If mechanical
adjustment exists such as with H-based laser stand).
Example: 12-ounce bottle sample result states
working distance 123 mm Working Distance.
Position laser marking head flat surface (area
outside of protective window; flat, black area) 123
mm from surface to be marked on 12-ounce bottle.
2) Based on Sample Report (PDF), were products sampled using Range Mode or Size
Mode ? If sample results not available, then measure distance from marking head to
location on each product to be marked (Working Distance).
 Is the difference between these Working Distances less than 42 mm? Use Size
Mode.
 Is the difference between these Working Distances between 42 and 50 mm? Use
Range Mode.
