1 Simple Operator Interface (SOI)
1.1 Introducción
Con el software "Simple Operator Interface" (SOI) se pueden seleccionar, editar y a través delsistema láser emitir plantillas de marcación de forma sencilla y poco complicada. El software
se puede utilizar en un PC normal o en una pantalla se establecerá una conexión con el sistema láser y así se tendrá acceso a las plantillas quetáctil. Después de iniciar automáticamente
se encuentran en la base de datos del sistema láser.
1.2 Condiciones
Para el funcionamiento perfecto deben cumplirscuanto a hardware y software:e como mínimo los siguientes requisitos en
Microsoft Windows 2000, XP o Vista
Procesador Pentium IV > 2 GHz
1024 MB RAM
Unidad de CD-ROM (opcional si SOI se debe instalar con CD-ROM)
Memoria de disco rígido 200 MB

1.4 Activación del software
El software se puede abrir opcionalmente haciendoen la interfaz del escritorio o simplemente haciendo clic en la opción »SOI« del menú de la clic doble en el símbolo SOI directamente

Si el software se activa por primera vez se debe establecer una conexión con el sistema láser.Esto sólo se puede realizar a través del nivel de usuario Administrator en el diálogo de
configuración, véase párrafo "Láser" en el capítulo "Configuración" en la página 15.
Después de llamar el software se establecerá automáticamentláser y se exhibirá la interfaz del usuario dele una conexión con el sistema nivel de usuario Operator. Para cambiar para el

Para operar el software SOI están definidos diferentes niveles de usuario. Las funcionesdisponibles dependen del nivel de usuario de la contraseña ingresada.

2.4 Seleccionar plantilla
Con el menú »Start Laser« se inicia el proceso de marcación. La plantillaseleccionada actualmente será colocada sobre el producto por el sistema
láser activo.
Durante la marcación el menú cambia para »Stop Laser«. Al hacer clic en elmenú el proceso de marcación corriente será parado.
Para seleccionar una plantilla proceda de la siguiente forma:
1.Haga clic en el menú abajo a la izquierda seleccionada actual. Se abre la siguiente ventana:en el que está el nombre de la plantilla
2.Seleccione la plantilla deseada de la lista. A la derecha se exhibirá una visualización delcontenido de la plantilla (la función de visualización se puede desactivar en »Descon.
visualización«
AtenciónDependiendo de la configuración de la entrada »Manipulación $« es posibleque no se exhiban todas las plantillas existentes en la base de datos del
sistema láser.
3.Confirme la selección con »OK«.
4.La ventana se cerrará y el contenido de la nueva plantilla se exhibirá en la ventana devisualización del SOI.
