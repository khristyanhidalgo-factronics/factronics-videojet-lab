How Focus is Achieved
Simplified version of how focus is achieved:
Pre - lens: minor focusing just to reduce power losses on internal aperture (the laser beam itself is slightly divergent)
1.lens: creating a focus between the two telescope lenses ( Keplar principle)
Telescope: optical component to vary the beam path length between 1. and 2. lens
2.lens: focusing output beam
Window (output): just ingress protection, not adding optical properties
Focal plane: varies with the beam path length between 1. and 2. lens determined by the telescope

Updated
Security Features TCS+
To improve security, TCS+ in CMark v. 5.x contains the following features:
• Upon install new passwords for default users must be created on first login (Administrator,
Supervisor, Operator). 2222, 1111 and 0000 used for initial login, but will be prompted to create new
password.
• User list not displayed and user must type in User Name to login ( can change to show list in
Users>Wrench icon>Login Settings ).
• Limits/rules on acceptable User names . Example: cannot create user called Admin or Admin1.
• Auto Logout on by default . Can disable, but even if disabled any Users with Administrator ROLE will

Power check procedure with SHC60/100/150 marking heads remains the same as previous models.
Make sure to take measurement out of focus (at least 50% out of focus) to prevent damage to meter!

• For power check with 3350 with SHC - SF marking head position target of meter less than 45 mm from
marking head or more than 220 mm away to avoid being in focus no matter the Working Distance setting.
• Create power check Job and use Pilot Laser > Job Elements to ensure you are hitting target of meter.
• Take first measurement at 20% Intensity setting to again ensure hitting target of meter.
• Stop and increase Intensity setting to 100% and take another reading.
