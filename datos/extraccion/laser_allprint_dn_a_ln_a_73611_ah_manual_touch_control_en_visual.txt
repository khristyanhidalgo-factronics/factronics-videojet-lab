1 Introduction
The Touch Control Software performs the following functions:
Generating and organizing jobs and parameter settings
Configuring the Line setup
Transferring data to the laser system
Using the Touch Control, with the Touch Control Software, you can generate and edit the mark-ing content of a job easily on your touch screen device. Your data is transferred to the laser
system through its integrated interface.
Training on the operation of the laser system and the Touch Control is offered regularly. Forfurther information, please contact Videojet Technologies Inc. or one of their representatives.

NoteBefore operating the laser system you must make sure that the safety instructions of the laser manual have been read and understood.

1.1.1 InstallationYou must have the laser marking system installed and set up as a Class 1 (I) laser system.
Refer to your local Videojet Distributor before you make any changes to the installation.
1.1.2 Power connectionIf the mains electrical supply is not connected, contact a Line Supervisor or a technician.
Before you start the system, confirm the following important points:
The Supply Unit key switch is in the off (0) position.
Any circuits connected to the interlock are closed.
Set the local electrical isolator switch for the laser system to the on (I) position.

2.10 Emergency shut down
The last mark information will be stored by the laser system.
If the shut down occurred during the editing of a mark, any unsaved data or changes will belost. During the time the laser is disconnected, certain buttons will be unavailable.
When the laser reconnects, any time or date information will be updated and unsaved informa-tion cleared from the touch screen. Normal operation can then be resumed.
If there is a hazard that prevents safe access to the Mains Power Supply Switch, operate thelocal electrical isolator switch for the laser system.
If there is a hazard that prevents safe access to the Emergency Stop Button, operate the laserisolator switch or the local electrical isolator switch for the laser system.
2.10.1 Restart after an emergency shut downTo restart the system after an emergency shut down, carry out the following:
1.Switch on the laser isolator.
2.After the Touch Control displays the Home screen and the laser connection has automaticallybeen re-established, touch the Start button on the Touch Control screen.
3.Start the production line.

QR MATRIX:The version of the QR code is defined, which can vary from 1 to 40.
VersionEach version consists of a different number of modules, for exam-ple, version 1 (21 x 21 modules) up to version 40 (177 x 177 mod-
ules). As each version can only store a determined maximum data volume, higher QR code symbol versions are required for more
extensive QR codes. The default value is 1.
LevelThe QR code is capable to fulfil error corrections to restore data if the code is dirty or damaged. Four error correction levels are avail-
able: L (approximately 7%), M (approximately 15%), Q (approxi-mately 25%) and H (approximately 30%). The higher the selected
level, the higher is the capability of the error correction. At the same time, the data volume of the QR code increases. The default value
is L.
ModeThe mode of the QR code can be defined here. When choosing the setting as 8 bit, only numbers can be used in the code. With the set-
ting Kanji, letters can also be used. If you select the Case sensitivity checkbox, lower and upper case letters are represented in the QR
code. The default value is 8 bit.
