Cooling Compressor
Creates filtered, cooled air for marking unit and air knife across protective
glass
• Diaphragm pump with linear magnetic motor
• Lifetime of compressor: 16,000 - 20,000 hours expected
• Air into pump is pre - filtered by front fan filter mats
• 2 Filters – 1 in - line and 1 bulb style filter on pump
– Maintenance: Change filters on pump every 6 months
• Orientation matters!! Pump must be rotated 90 degrees if installing supply
unit in an orientation other than feet down.
• Air pressure monitored at LIC board – if pressure is too high or too low then
error will occur. Monitors pressure in millibars, not air flow (120 - 180 mb
acceptable)
• UADB (Universal Acceleration Detection Board) - detects the
orientation of the air pump. If the supply unit is installed vertically, the UADB
board generates an error message when the pump orientation was not changed
according to supply unit orientation.

2. System Overview
7010/7020/7030

Videojet Lightfoot Canning Solution
Hardware and software combined to create IP65 rated fiber laser system
that can mark up to 100,000 cans an hour.
Confidential - Company Proprietary

Overview
Benefits:
• Mark up to 100,000 cans per hour using two 7440 lasers (maximum 18
characters, OCRB font at 2.5 mm font height; no more than 2m/sec line speed for
67 mm diameter cans) when using two 7440 lasers together in system.
• Comprehensive solution - for many beverage can marking applications.
Single supplier for turnkey solution - IP65 fiber laser system and beam
shield for use on conveyor (post - filler location).
• Standard beam shield tunnel (300mm or 600 mm width) covers many
straight - line conveyor applications after the filler.
• Single TU430 Interface provides control of 2 lasers with a
Leader/Follower setup.
• Complete system meets Performance Level D and can meet
Performance Level E/Class 1 standards* (7010, 7020 and 7030
together).
• Modular: Main components can be ordered separately (7010, 7020 and
7030) or together where complete system is needed and fits.
Confidential - Company Proprietary

Overview
Limitations:
• Beam shield tunnel will not fit every conveyor application but fits many
common ones.
• Only TCS+ TU430 interface for 2 laser system. No SmartGraph or
CLARiTY .
• If using complete 7020/7030 together then can only use CFS - M
marking head ( straight marking head with medium marking field with
special mounting block). No other head configuration can be used
with 7020/7030 system.
• No logos, barcodes or synchronized data when using dual lasers.
DataMaster software will not be supported at launch. Might be
possible in the future.

Dual Laser Systems – Leader/Follower Designation
❖ Follower laser Mark Settings will all be taken from Leader laser.
❖ Follower laser only adjustment will be for Intensity, but only as an offset
from the Leader setting (uses Leader % and Follower can be offset from
that in + or – increments)
❖ Because laser output power varies from unit to unit, suggested to make
the laser with higher output power the Follower.
❖ That way can adjust Follower up if necessary to create consistent
marking.
❖ If Follower is lower output power then may reach upper limit of
capability, but will not know it.
Use information from traveler sheet (received with laser) to determine which
should be Leader (lower output power) and Follower (higher output power)

5. Dual Laser Marking Head
Alignment

Overview of Software
CMark version 4.9 contains functionality for Multi - Laser Mode in TCS+.
• Splits the code across two marking heads. Each marking head prints
alternate characters in message like example below.
• Allows for much higher throughput than single laser would allow.
• Single time and data source so no synchronization needed.
• No serialization, barcodes, or logos allowed with this feature.
• SmartGraph and CLARiTY do not support Multi - Laser Mode.

What if…. Leader Laser Fails (part 1)
If Leader laser fails and cannot be recovered in a timely manner then more steps
are necessary to switch to only using Follower laser. The following checklist is not
exhaustive and these steps will vary based on the complexity of the application.
The following is only a suggestion and intended to make person doing the
changeover aware of what might need to be moved/adjusted/installed.
To use only Follower in multi laser installation:
• Copy Jobs, Mark Settings and Line Setup from Leader laser to USB.
• Disable Multi Laser Configuration in Laser Unit Settings> Laser Configuration
• If MIC board present, then disable through Laser Unit Settings.
• Shut down both lasers.
• Remove MIC board and install into Follower (if Follower does not already have
a MIC board)
• Move TU430 (if present, from Leader to Follower)
Confidential - Company Proprietary

What if…. Leader Laser Fails (part 2)
• If only using encoder and photo eye, then just move wires for these items from
Leader to Follower, but in cases where several additional IOs are also wired into
Leader’s customer interface, the following is suggested:
o Remove the cable gland frames holding cables coming into Leader laser
Customer Interface (one on rear of drawer and one on rear of laser).
o Remove top of cable gland frame of supply unit (leave cable gland plate from
rear of drawer assembled).
o Remove any connectors on Customer Interface that have wiring connected
from outside the laser (Photo eye, encoder, ready to mark, etc.). Leave wires
attached. Just unlock connectors and remove from board.
o Slide blocks with cables through them out of frame.
o Put these cables with connectors and the remaining intact cable gland frame
onto the Follower laser (remove ones already in place).
o Remove the wires for the cable that created the daisy chain for encoder
pulses and trigger. Keep in safe place for later reinstallation.
Confidential - Company Proprietary

What if…. Leader Laser Fails (part 3)
• How was voltage for Customer Interface provided?
o If Internal Voltage was used (no incoming customer voltage on X28 pins 7
and 8) then nothing further necessary for this.
o If External Voltage was used (customer voltage on X28 pins 7 and 8), then
ensure X28 pins 7 and 8 have Voltage and GND connected and that X19 and
X20 jumpers are set to pins 2 - 3 (this should already be done if wired
according to recommendation).
• Install MIC board in Follower (if applicable).
• Boot Follower laser.
• Enable the MIC through TCS+>Laser Unit Settings>External Interface (if
applicable). IP address should be the same as it was set to in Leader. That way PLC
does not notice a difference.
• Import Jobs, Mark Settings and Line Setups onto Follower laser.
• Edit Line Setup: Trigger> “Start Delay” by adding 43.5 mm to the Start Distance to
compensate for the Follower laser marking head position.
