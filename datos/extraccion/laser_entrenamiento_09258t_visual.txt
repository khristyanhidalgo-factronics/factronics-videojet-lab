Simple Printer P rotocol
For Lasers
1. Host Port Configuration:
TCP Client, Port 20000
2. Timeout :
None.
3. Basic format:
REQUEST: <Command>|<Parameters><CR><LF>
RESPONSE: <Result>|<Parameters><CR><LF>
4. Parameters:
<TName> = Template Name (case sensitive)
<VName> = Variable Name (case sensitive)
<VSize> = Variable Data Size
<VData> = Variable Data
<VType> = ET,SN,DT or TM (ExternalText,SerialNumber,Date or Time)
<TPos> = Template position (xOffset yOffset Rotation) eg. "10 20 180.000"
<TText> = Template text
<OType> = Object Type (Text, Barcode or IDMatrix)
<PState> = ON, OFF, ERR or CHK (ERR and CHK are readonly)
<Result> = ACK or NAK:Reason
< Hours > = Operating Hour s ( 6509 )
<Clock> = Date and Time (2008 - 04 - 20T04:04:12)
<PCount> = Print Count
< L Size> = Lot Size
< LCount > = Lot Count
<ECode> = Error Code
< PDone > = ON or OFF
<SarNum> = SAR Number and Revision
<T Info > = Template Inform ation (MarkingTime VectorCount PointCount MarkingDistance
JumpDistance Height Width Xmax Xmin Ymax Ymin) eg. "129 10 321 161.77 35.91 12.04
56.89 28.45 - 28.45 6.02 - 6.02"

7 . Print Done
When PDone is ON, the following wi ll be sent to the host device:
If no unacknowledged errors exist
PRN|OK<CR><LF>
Else
PRN|ERR<CR><LF>
Note that PDone defaults to OFF whenever a TCP Connection is established.
8 . Translate PState
The PState strings are defined in the \ smarties \ custome r \ pstate.txt file located on the MMC card.
This is simple text file that can be edited to change the default PState strings as required by your
application. To translate these states, edit only the text within the quotation marks for each state.
