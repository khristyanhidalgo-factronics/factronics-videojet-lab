1 Introduction
Basic TCL Script for Alltec Lasers
1.1 Protocol
- TCP / IP
- Server / Client Applikation
- Laser = Server
- Customer Network device = Client
- Port 20001
- Datastring must be UTF8-Characters
- End of Datastring must be CR,LF (0x0D,0x0A)
1.2 Contruction of Datastring
- Command: Command;Arguments;[CR][LF]
- Answer good: [ACK];ResultCode;Arguments;[CR][LF]
- Answer bad: [NAK];ResultCode;[CR][LF]
- Command Text is not case sensitive
- ResultCode is 0000 if everything works correctly

1.4 Command Details
1.4.1 Start;
Starts the laser process
- Answer: [ACK];0000;
1.4.2 Stop;
Stops the laser process
- Answer: [ACK];0000;
1.4.3 GetStatus;
Returns the current Laser status
- Answer: [ACK];0000;LaserStatus;
1.4.4 GetVarNames;
Returns all Variablenames used in the active Templa te
- Answer: [ACK];0000;VarName1;VarName2;VarName3;
Additional Information:
- Return arguments may include Prompt, Serialnumber s, Date and Time variables
1.4.5 GetVars;
Returns all variables used in the active template a nd their values
- Answer: [ACK];0000;VarName1=VarValue1;VarName2=Va rValue2;VarName3=VarName3;
Additional Information:
- Return arguments may include Prompt, Serialnumber s, Date and Time variables
1.4.6 GetVars;VarName1;VarName3;
Returns the values of the named variables
- Answer: [ACK];0000;VarName1=VarValue1;VarName3=Va rName3;
Additional Information:
- Return arguments may include Prompt, Serialnumber s, Date and Time variables
1.4.7 SetVars;VarName1;VarValue;
Sets the value of the given variable
- Answer: [ACK];0000;
Additional Information:
- Arguments may include Prompt and Serialnumbers va riables
- SmartGraph/LinxDraw/FobaDraw does not update its screen when variables change in a template list
