Installation Instructions
Preface
In the following instruction it is shown how to configure the TCL script a t the laser .
Requirements
Laser with software versions minimum QMark 8. 5. x or CMark 2. 3.x
Preparation
Switch off the laser. Remove the MMC /SD car d from it. Put the MMC/SD card into a suitable
card reader which is properly connected to your PC. Copy all files and sub - folders into the
appropriate folder on MMC/SD card . Replace existing files if necessary.
On QMark (ACC3) based systems with QMark ver sion < 8.6 , copy all files to
[MMC]/smarties/customer and overwrite existing files
On QMark (ACC3) based systems with QMark version >= 8.6, copy all files to
[MMC]/smarties/customer /tcl and overwrite existing files
Copy file “ startup.sh ” from subfolder “ Startup QMark 8.6 ” to
[MMC]/smarties/customer / and overwrite the existing file
On CMark (Chameleon) based systems, c opy all files to
[SD]/smarties/customer/tcl and overwrite existing files
