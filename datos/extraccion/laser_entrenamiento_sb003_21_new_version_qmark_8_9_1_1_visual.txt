What is new?
Switching to safe error state with message "E00108" on internal communication problem (QMRK-2620).
DotCode fixed size support (SG-4164).
Implementation of microQR and PDF417 code (SG-4165).
Support of LF101, LF201, 7220, 7320 added (SG-3702).
Remote Service support for Acc3 systems added (AOS-633).
Tube monitoring for fiber laser added (AOS-671).
Support of LF101, LF201, 7220, 7320 added (QMRK-2447).
Implementation of CO2 tube monitoring (QMRK-2477).
Update time zone data (QMRK-2629).
Web interface issues on Windows 10 (QMRK-2623,QMRK-2624, QMRK-2626, QMRK-2627).
Major issues resolved:
Broken binary content for QR code fixed (SG-3801).
Checknumber in RSS14ST, RSSLIM and RSDate variable (SG-3740).SLIMGP barcode covers first digit of
Chinese SG shows summer time zone "None" even Central Europe is selected (SG-3742).
Wrong scaling of a rotated date variable after changing setting for Date Change (AOS-628).
EAN 128 "AI 421" uses wrong length (AOS- 631).
BC128 incorrectly rendered making it unreadable (AOS-818).
Execution of MOTF-related commands often drops TCL connection (QMRK-2452).
