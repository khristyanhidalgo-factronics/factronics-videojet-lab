For adjusting the mode aperture the following is requiredpower-measuring device (66517)

1.Open the housing cover of the laser head.
2.Remove the laser scan lens (see section "Disassembly of the Laser Scan Lens" in chapter"Maintenance").
There are two possibilities for adjusting the mode aperture:using the indicator disk of the adjustment kit or
using the power-measuring device
1.1 Indicator Disk
ImportantThe following steps are carried out with closed key switch (position1).

4.Wait until the message »Key switch open« is displayed on the touch screen.
5.Turn the key switch to position »1«.
6.Start the Smart Graph software.
7.Select mode aperture 1.3.

1.2 Power-Measuring Device
1.Position the power-measuring device centered below the opening of the marking head.
Attention2.Connect the mains supply.
3.Switch on the main switch.
4.Wait until the message »Key switch open« is displayed on the touch screen.
5.Turn the key switch to position »1«.
6.Start the Smart Graph software.
7.Check during the adjustment whether the laser beam hits the center of the detector surfaceof the measuring device.
8.Select mode aperture 1.3.
9.Go in the Smart Graph software to Configuration > Service > Laservalue to 22 to 25 A, the value of the RF amplitude to 0 and select »Shutter open«., set the current
10.With »Apply« the values are transferred to the laser system (if you want to save the valuesto the permanent memory you have to save the database in user interface »File«).
Power can be measured1.Adjust the mode aperture with the xy adjusting screws until the maximum power is set.
2.Close the housing cover of the laser head.
No power can be measured1.Select the next bigger mode aperture until the measuring device indicates a power value.
2.If no power is displayed even with the biggest aperture check the position of the power-mea-suring device.
3.Adjust the mode aperture with the xy adjusting screws until the maximum power is set.
4.Select the next smaller mode aperture and repeat step 3 until you have reached mode ap-erture 1.3.
5.Close the housing cover of the laser head.
