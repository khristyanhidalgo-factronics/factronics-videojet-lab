S o l u t i o n
1. Inspect all variables for correct configuration.
Print force setting. For 6530/6330/6230 the range is 2.0 – 3.5 kg
Print darkness level set to 85%
Line speeds
Consumables set properly (ribbon)
PH gap set to 2.5mm
Installation bracket square / balance
2. Remove the Cassette.
3. Manually move the printhead to the center of the print area.

4. Remove the printhead.
5. Inspect the two screws which fasten the carriage to the timing belt.
6. If these screws are loose:
1. Remove one of the screws.
2. Apply one small drop of Loctite 243 to the tip of the removed screw .
3. Reinstall the screw and tighten.
4. Repeat for the second screw .
5. Allow the printer to site idle for one hours before printing again.
