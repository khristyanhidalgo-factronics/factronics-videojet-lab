Accessing Faults and Error Messages in SmartGraph
1. Login as level 1 using
2. Select the Laser Operation tab.
3. Select the Messages tab to View details of error code.
Accessing Faults and Error Messages in TCS+ or Legacy TCS on Touch US
1. Log in as Operator level or higher. The banner Will be yellow or red if an alert is present.
2. Select the i icon in the banner for error code details. If the banner does not show an i icon, no
alert has been asserted.

Accessing Faults and Errors in SOI
Note that some people use the term "SOI" and "Panel PC" interchangeably, so it is important to
confirm which software is in use before proceeding with troubleshooting since the Panel PC
may be running SOI, SmartGraph, or TCS.
1. Login as Operator level or higher.
2. Select the on upper left tab to View fault or warning details.
Accessing Faults and Errors in CLARiTY Laser Controller (CLC) I Clarity Pod
1. Login to Level 1 or higher.
2. Click on the red or yellow banner to View the error or warning details.
