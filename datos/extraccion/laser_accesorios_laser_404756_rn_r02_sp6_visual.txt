Case# E01064 NAME Graphic Support added Type: Enhancement
Summary Description Required Software Version (or later)
CLARiTY Laser Controller now loads Logos
CCM CLARiSOFT
Not Applicable 4.409 SP11
Details:
First, logos will have to be loaded onto a marking system via Smart Graph.
After Logos have been loaded onto a marking system, the CLC will need to be re-
powered for the logos to be visible to CLC.
Then, CLARiSOFT jobs can be created with the same logos referenced that are already
existing on the marking system.
These jobs can then be sent to (and printed by) the CLC-Laser system without issue.
Logos that are rotated AND stretched at the same time are not supported.
This change requires CLARiSOFT 4.409 SP11 (or newer) to create the job files.

Case# E01065 NAME Various 1-D Barcodes now supported Type: Enhancement
Summary Description Required Software Version (or later)
EAN13, ITF, Code128 and EAN-128 Barcodes now supported
CCM CLARiSOFT
Not Applicable 4.409 SP11
Details:
This change requires CLARiSOFT 4.409 SP11 (or newer) to create the job files.
Known issues:
There may be some minor sizing and positional issues seen on the CLC screen with
specific sizes of some barcodes.
Merging of data from existing fields into barcodes may cause issues if the data requires a
check-digit.
Example: if 13 digits are required to be merged into an EAN13 barcode this can be
successfully achieved 1 of 3 ways on other CLARiTY printers.
1. Merge 13 (correct) numeric digits from an existing text field - On the CLC UI the job
will appear ok but the marking system will have a blank job.
2. Merge from a text field containing 12 numeric digits + Checksum appended to it - On
the CLC UI the job will appear ok but the marking system will have a blank job.
3. Merge from a text field containing 12 numeric digits - on the CLC this is successful as
the the Marking System generates its own text field.

Case# E01129 NAME Interlock and Shutterlock behaviour Type: Enhancement
changes
Summary Description Required Software Version (or later)
Some faults that were user-clearable now self-clear
CCM CLARiSOFT
Not Applicable Not Applicable
Details:
When Interlock and/or Shutterlock safety circuits are opened a number of faults and
warnings are rasied.
Some would be raised as a FAULT, which was undesirable becase there is no issue with
the marking system.
Some would auto-clear, while others would not (that should).
CLC r02 SP6 (and newer) have been modified so that:
1. E6251 Interlock Open - This should be a WARNING that stops the laser from printing
and also self-clears when the Interlock is closed.
2. E6252 Interlock Timeout - This should be a WARNING that stops the laser from printing
and also self-clears when the Interlock is closed.
3. E6256 Laser shutterlock open - This should be a WARNING that stops the laser from
printing and also self-clears when the Shutterlock is closed.
4. E10304 Marking process interrupted by interlock - This should be a WARNING that
does not self-clear.
5. E10305 Keyswitch has been opened while marking - This should be a WARNING that
does not self-clear.
6. E19505 The safety circuit is open - This should be a WARNING that does not self-clear.
7. E19506 The front panel keyswitch is open - This should be a WARNING that does not
self-clear.
Note: 4-7 do not stop the laser from marking, i.e. usual WARNINGS.

Case# B01062 NAME Decrementing Counters now load as Type: Bug Fix
expected
Summary Description Required Software Version (or later)
Decrementing counters no longer cause 'Job Download Failed' Faults
CCM CLARiSOFT
Not Applicable Not Applicable
Details:
The way in which CLARiSOFT and Smart Graph generate decrementing counters is
different and would cause 'Job Download Failed' Faults if such a counter created in
CLARISOFT was loaded on CLC's running software prior to r02 SP2.
With r02 (and newer) software, these differences have been overcome and such counters
load and count down as expected.
This fix does not depend on CLARiSOFT version.

Case# B01067 NAME Datamatrix Barcode Alignment Fixs Type: Bug Fix
Summary Description Required Software Version (or later)
Datamatrix barcodes now appear in the expected position relative to other fields,
barring some rounding errors
CCM CLARiSOFT
Not Applicable 4.500 SP1
Details:
With previous revisions of software to r02 SP2, Datamatrix barcodes would appear
shifted from the expected position when printed.
With r02 (and newer) software, the laser now prints Datamatrix barcodes where the CLC
User Interface (and CLARiSOFT) indicates they should be printed.
Additional positional issues were identified with varying module sizes of 2-D barcodes.
These changes have been resolved with r02 SP4 (and newer software).
The module size fixes require existing jobs to be opened in CLARiSOFT 4.500 SP1 (or
newer) and the Module Sizes saved as a new value. The jobs should then be re-
downloading to your CLC.

Case# B01105 NAME Fix for Total Count doubling with Type: Bug Fix
Interlock open
Summary Description Required Software Version (or later)
Interlock being opened too quickly after a mark has finished no longer interferes
with Counter values
CCM CLARiSOFT
Not Applicable Not Applicable
Details:
Previously, if the Interlock was opened within a second of a mark finishing, the Total
Count value would double (and then subtract what the Batch Count was) and the Batch
Count would be populated with what the Total Count should have been.
Re-powering the CLC would re-synchronise the count values.
Counters within the job could also be affected.
With r02 SP4 (and newer software) this no longer happens and all counter values behave
as expected.

Update Procedure
In order to update a machine with a previous software revision to the latest you should use
a USB memory device or the latest CLARiTY Configuration Utility.
a) To use a USB memory device, the CAB update file requires copy and pasting into a
‘CLARITYupdate’ folder in the root of the USB device. Insert the USB device into the port
on the printer and after a short while the screen may show an option to load new
software, depending on the printer settings in CCFG. If it does select ‘Yes’ then select the
required update, press ‘OK’ and follow on-screen instructions. If it does not, keep the USB
device in the printer and on the printers User Interface scroll to
Tools\Setup\Control\CLARiTY Update, select the required update and press ‘OK’ and follow
on-screen instructions.
b) To use the CLARiTY Configuration Utility, start the utility, and connect it to the printer
you wish to update. Ensure that the CLARiTY Configuration Utility has a valid TCP/IP
connection to the printer; this can be observed by the printer icon turning green, and the
"Active Connection" message being displayed in the status pane.
Right click on the name of the coder you wish to update and select the CLARiTY Update
option. Then locate the file with the same name as the part number above, and the
CLARiTY Update will then proceed automatically.
