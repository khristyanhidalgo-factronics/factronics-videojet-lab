1 Exchange of the Customer Interfaces
For exchanging the customer interfaces the following is required:insulated screwdriver (66797, accessory kit)
offset hex key 2 mm
1.1 Preparation
DangerBefore starting any work the laser system must be dead!1.Turn the key switch to position »0«.
Remove the key to ensure that the laser system cannot be switched on.
2.Wait until the message »Key switch open« is displayed on the touch screen.
3.Switch off main switch.
4.Disconnect the mains supply.
5.Loosen the four screws (2 turns) of the interface cover at the back of the PCM and removethe interface cover.

Exchange of the Customer Interfaces
1.2 Exchange of Interface CI-FAST-IN
1.Disconnect the supply line (24 V).
2.Unlock and disconnect the connector.
3.Unlock the CI-FAST-IN by lifting both levers(see figure) using the insulated screwdriver.
4.Remove the interface CI-FAST-IN.
5.Insert the new CI-FAST-IN interface.
6.Connect and lock the connector.
7.Connect the supply line.
8.Mount the interface cover.
1.3 Exchange of Interface CI-CAN-IO
1.Remove the interface CI-FAST-IN (see section "Exchange of Interface CI-FAST-IN").
2.Unlock the interlock by lifting both levers (see figure) usingthe insulated screwdriver.
3.Loosen the screw under the interlock two turns.
4.Loosen the screw of the fixing rail and push the raildownwards.
ImportantThe modules of the interface CI-CAN-IO must be exchanged successively.
5.Pull out the orange extracting aid of the module to be exchanged and remove the module.
6.Insert the new module.
If several modules are to be exchanged repeat steps 5 and 6 for each module.
7.Mount the rail.
8.Mount the interface CI-FAST-IN (see section "Exchange of Interface CI-FAST-IN").
9.Mount the interface cover.
