1.4 Uploading HiRes File
1.Log into TCS+/FOBA Go/LinxVision as "Service".
2.Go to Global Settings and select Laser Unit Settings.
3.Select Lens Compensation and select File Management.
4.In the File Management dialog select Upload and navigate to the corresponding HiRes file(on USB stick, connected laptop, PC or TU4x0).
NoteAll HiRes files can be found on the Service Pages under Software > HiResFiles > SHC-SF. The folder name contains the serial number correponding to
the number of the marking head and board.
5.Select the file to be uploaded. It will automatically be copied to the correct category.
6.In the Lens Compensation now select Activate best compensation.
7.Close the Laser Unit Settings dialog.
