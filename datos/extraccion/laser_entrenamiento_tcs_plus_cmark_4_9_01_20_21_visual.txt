TCS+
➢ Always installed and accessible (no licensing)
➢ Exists only on Multi - Core Chameleon boards
➢ Is part of the CMark version 4.x image
➢ Lives in flash memory of Q7 on Chameleon board
➢ Can be accessed by any web enabled device or TU430
➢ All of the features of TCS, plus added features including Event Log,
Electronic Signatures option, and enhanced security settings
➢ To access TCS+: enter IP address of laser into web browser on any
device on the same network

New Features in CMark 4.7 (released 2019)
• Most of Web Interface is now available in TCS+
• Service user Login in TCS+ requires “Daily Password”
• Focus Finder feature activated via TCS+ only. No other user interface can
activate. (Only 7340/7440 has Focus Finder in this CMark version)
• Comms Monitor to check data sent to/from PLC ( EtherNet /IP and PROFINET)
• Faster boot time for laser
• Single User Functionality (higher level kicks out lower)
• Homescreen live without Login
• System Information page allows .PDF export

• Multi Laser Support

Focus Finder
Focus Finder now in Main
Menu (Home screen) too
in CMark 4.9 (not all
models support Focus
Finder feature).
Keyswitch must be armed to use Focus Finder because pilot laser is used and that is part of the
laser source.
Enabling Focus Finder temporarily turns on pilot beam and alternates two images very quickly between galvos
and a mirror in marking head used specifically for focus finding purpose. Images switch too quickly for human
eye to notice so it looks like one image. Only when in focus will the dot and circle overlap due to the angle of
mirror in head.
