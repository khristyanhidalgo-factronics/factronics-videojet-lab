Due to market-wide electronic chip component shortages, V ideojet has redesigned the 6330 32mm/53mm and 6530
53mm main printer PCB.
The new main printer PCBs have undergone rigorous testing and there should be no dif ference in form, fit, or function.
https://videojet.my .salesforce.com/articles/en_US/Knowledge/New-Main-Printer-PCB-for-6330-32mm-53mm-and-6530-53mm-Printers/p 1 /4
For now , the 6530 107mm main printer PCB remains unaffected.
I m p o r t an t C o m p at i b i l i t y I n f o r m at i o n
Board Compatibility
The new 6330 main printer PCB is compatible with any 6330 printer .
The new 6530 53mm main printer PCB is compatible with any 6530 53mm printer .
Jobs, Archives, and Clones
Jobs, archives, and clones from old 6330 main printer PCB are compatible with new 6330 main printer
PCB and vice-versa.
Jobs, archives, and clones from old 6530 53mm printer PCB are compatible with new 6530 main
printer PCB and vice-versa.
Leader-Follower configuration
Leader-Follower configurations are possible with a mixture of printers with old main printer PCBs and
printers with new main printer PCBs.
In short, whatever was possible/supported with old main printer PCBs will still be the case with new main printer PCBs.

printer PCBs. T able 1 lists the software versions for old and new main printer PCBs.

versions are on an inserted USB stick, the respective PCB will only see corresponding software for the given PCB on that
USB stick. If the incorrect software version is sent via Clarity Config, the printer will raise a warning similar to those shown
in Figure 1 and Figure 2 and will not load the software onto the printer .

If you are unable to power on the printer or are unable to access that screen, you can determine if it is an old or new main
printer PCB by taking note of the board itself. The old main printer PCB (Figure 3, left) has the Windows CE sticker located
directly below the micro SD card. The new main printer PCB (Figure 3, right) has it located elsewhere.
Sticker Placement V ariation
The placement of the Windows CE sticker on the new main printer PCB may deviate from Figure 3 in future revisions, but
it will nevertheless be placed in a location other than that of the old main printer PCB as there are now electronic
components in that location on the new main printer PCB that would keep the sticker from laying flat.

The starting serial number of the first printer with the new main printer PCB installed is 2223019002TZH.
As of publication of this bulletin, there will only be a small number of new main PCBs (~30) used. Once stock of
old main PCBs depletes, manufacturing will install the new main PCB in every new printer . Our estimation is that
this will occur as early as September 2022.
S p ar e P ar t s
Because the new main printer PCBs do not af fect form, fit, or function, they will continue to use the existing spare part
numbers. However , a new part number will be introduced for the micro SD cards, which will have the new software
revisions for the respective new main printer PCB model. As of publication of this bulletin, the new main printer PCB is not
being used for spares purposes. Usage for spares will likely take place once stock of the old main PCB depletes. Our
estimation is that this will occur as early as September 2022.

Micro SD Cards Are Not Interchangeable
Do not install a new micro SD card on an old main PCB, or an old micro SD card on a new main PCB. While doing so
would likely not damage the main PCB, the printer will likely only display a black screen and not boot.
